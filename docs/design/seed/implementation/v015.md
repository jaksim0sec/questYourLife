## Bottom Sheet 핵심 제스처 계약

- `pointerDown → tracking → release/cancel`. 손을 움직이는 **동안 높이가 실시간으로 따라오고**, release 시 **놓은 높이에서 가장 가까운 유효 snap**으로 애니메이션 정착. 55px/속도 기준으로 한 단계씩 변경하는 옛 규칙 폐기.
- Handle은 항상 drag. Body는 `scrollTop > 0 && scrollTop < max`이면 **Native scroll 우선**. **상단에서 아래로** 잡아당기는 잔여 이동량은 시트 축소로, **하단에서 위로** 잡아당기는 잔여 이동량은 시트 확장으로 연속 인계.
- 터치 취소는 이전 안정 snap 복원. Escape / Back / Backdrop / 명시 닫기로 닫고 원래 focus 복귀. Keyboard ArrowUp/ArrowDown 및 눈에 보이는 상태 버튼 제공.
- 최소 높이는 **내용 기반**(시연은 최소 185px, 최대 약 40vh/380px); 중간은 약 65vh, 전체는 OS inset을 제외한 가용 높이. 내용이 짧으면 중복 snap 삭제; Android IME·안전 영역 재측정.
- CTA Footer는 본문 scroll에 섞지 않으며 안전영역을 한 소유자가 한 번만 계산. 사용자가 입력 중인 값을 파괴하는 swipe dismiss는 별도 확인/제한 적용.

## 범위와 회귀 방지

- 기존 UI 시연: 앱 화면 7, 컴포넌트 30, 표면 10, 패턴 13, 제스처 6, SVG 56. 시연 카탈로그 수량이지 Android 실제 구현 수량이 아님.
- 기존 실앱 `main`의 클랜 네비 **나침반** 자산과 캐시 래스터 아트 변경 금지. 새로운 `users.svg`는 그룹 후보로만 사용.
- 예전 시드 문서는 구현 근거로 이력 보존. 모든 값을 무조건 approved로 변경하지 않는다. 기능/계정/동기화/실데이터 화면, 최종 하단 IA, 네이티브 접근성·런타임은 별도 완료 기준.
- 구현 시에는 `C-SVG→C-ACTION→P-BTN-ICON`, `C-SURFACE→P-HIERARCHY`, `C-SHEET→C-GESTURE→P-SHEET` 의존 관계를 지키고 새로운 상자/variant를 먼저 늘리지 않는다.
