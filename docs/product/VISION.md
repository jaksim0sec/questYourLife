# 제품 정체성 · 왜 갓생패치를 만드는가

**핵심 정의 [2026-11-12 최신 방향]**: 갓생패치는 **AI가 현실의 습관·루틴·목표를 퀘스트로 기획하고 적응시키는 앱**이다. 현실 행동의 성취는 XP·Cash·꾸미기와 연결되며, 친구와 협업·교류할 수 있다. 메인은 습관 만들기·루틴, 장기 목표 달성은 베타. 단순 투두앱도 즉흥 놀이·SNS 앱도 아니다.

> 최신 우선순위는 [D-017](../DECISIONS.md)를 따른다. 아래 2026-11-04~06 구상·인용문은 제품 역사로 보존하며, 최신 합의와 충돌할 경우 새 합의가 우선한다.

## 1. 출발점

사용자는 네이버 웹툰의 《퀘스트지상주의》 등에서 인생에 퀘스트가 부여되고 주인공이 자기 삶을 공략하는 소재를 접했음. 이러한 소재가 유행했다는 말은 **창작 동기의 설명**이며 별도 시장 통계로 검증된 주장이 아님.

> “우린 이제 ai 가 있잖아. ai 를 통해서 내 상황이나 목표 같은걸 말하면 퀘스트로 만드는게 가능하지 않을까?”

> “그렇다면 이걸 활용해서 위의 소재를 현실처럼 만들 수 있지 않을까?”

핵심 차이: 가상의 게임을 따로 플레이하는 게 아니라, **현실의 목표와 행동이 실제 플레이 대상**이 됨.

## 2. 반드시 같이 지켜야 할 두 축

### A. 현실 자체가 게임이어야 한다 [원칙]

> “과하게 게임으로 넘어가버리면 안됨. **내 인생이 공략 대상이자 게임임**. 여기서 내 인생과 아예 관련 없는 게임적 요소가 생겨버리면, 본질적인 목적이 흐려짐.”

퀘스트, 도전, 성장, 결과는 현실과 연결되어야 함. 게임성의 양을 늘리는 것 자체가 제품의 목표가 아님. 무관한 게임 모드·세계관·전투를 더하는 것은 현재 구상의 근거가 아님.

### B. 재미의 중심은 '나를 가꾸는 것' [원칙]

> “솔직히 까고 말해서 퀘스트 자체는 재미있는 소재가 아니야.”

> “궁극적으로 내 마이페이지와 내 마스코트를 내가 원하는대로 가꾸는것이 재밌는것이고, 애초에 보상도 다 그거에 관련된거임.”

> “즉 퀘스트는 수단임. 단, 동시에 이 앱의 본질임.”

이 세 문장을 **대체 가능한 한 문장으로 뭉개지 말 것**. 퀘스트는 실제 행동을 만드는 필수 구조이자 수단이고, 꾸미기·나의 흔적·친구와의 관계가 사용자가 체감하는 즐거움을 증폭함. 둘 중 하나만 강조하면 제품을 잘못 이해한 것임.

## 3. 이 제품은 무엇이고 무엇이 아닌가

| 갓생패치가 지향하는 것 | 피해야 하는 오해 |
|---|---|
| 현실 목표를 퀘스트로 해석해 실제로 수행 | 목표와 관계없는 별도 게임의 플레이 |
| 꾸미기·성취·소통이 연결된 플랫폼 | 체크리스트에 재화 배지만 추가한 앱 |
| AI가 기획·제공하고 사용자가 실행하는 습관·루틴·퀘스트북 | 매번 사용자가 수동으로 적는 체크리스트만 있는 앱 |
| 마이페이지를 가꾸고 보여주는 사회적 정체성 | 프로필을 설정 화면의 부속품으로 취급 |
| 친구 활동·공동 도전과 선택적인 클랜·이벤트 | 소셜 피드나 경쟁이 메인이 된 앱 |

> “단순 할일 앱을 퀘스트라는 특성 뿐만 아니라 sns 적 특성 + 게임적 인터테인먼트 + 트렌디한 소통형 플랫폼을 만드려는 것임.”

이 표현은 퀘스트 / SNS / 엔터테인먼트 / 소통을 서로 떨어진 부가기능이 아닌 하나의 제품 정체성으로 연결하려는 의도임.

## 4. 사람과 트렌드가 만드는 플레이 감각 [이전 구상 · 2026-11-06 기록]

> “단순 퀘스트에서 끝나는게 아니라, 클랜과의 협업, 랭킹과 순위의 경쟁, 퀘스트북과 이벤트등으로 유저간 형성되는 트렌드, 그리고 마스코트를 꾸며서 나를 투영하는 만족감”

퀘스트 수행은 출발점이다. 클랜에서 함께 도전하고, 순위를 통해 경쟁하며, 사용자가 만든 퀘스트북과 이벤트를 발견·참여·전파하는 흐름이 있어야 한다. 이용자가 서로의 활동과 유행을 체감하면서 다시 도전할 이유가 생기는 것이 핵심 경험이다. 치지직·당근·유튜브·인스타는 그 **연결감과 계속 새로워지는 체감**을 설명하는 참고 대상이다. 각 서비스의 피드나 기능을 그대로 복제하라는 지시는 아니다. 실시간 갱신 방식과 공개 범위는 별도 설계 대상이다.

현실에서 실물 보상을 줄 수 없기에, 붉은 도장 얼굴을 **현실적으로 생긴 트렌디한 이어폰·모자·패션 소품**으로 꾸며 나를 투영하는 만족감을 만든다. 실제로 획득한 듯한 보상 아트와 절제되고 깔끔한 일상 UI를 함께 써서 게임하는 듯한 감각의 강도를 조절한다. 이 흐름을 한 화면의 기능 목록으로 축소하지 말고, **현실 행동 → 사람들과의 협업·경쟁 → 유저 콘텐츠와 유행 → 보상 획득 → 자기표현 → 다음 참여**가 이어지는 경험으로 검토한다.

## 5. 이번 방향 정정 · 퀘스트 자체의 재미를 회복한다 [최신 원칙 · 2026-11-12]

1. **습관 만들기·루틴이 핵심:** 현실에서 지속할 이유가 있는 행동을 AI가 알맞은 퀘스트로 제안·조율한다. 장기 목표 달성은 베타 범위다.
2. **AI가 콘텐츠 공급자:** 사용자의 요청을 기다려 계획만 쪼개는 비서가 아니라, 사용자가 허용한 상황·진행 기록을 바탕으로 오늘의 퀘스트와 후속 전개를 기획한다. 재미는 유행어가 아닌 현실 적합성·새로움·성취에서 발생해야 한다.
3. **친구들의 활동은 연결 계기:** 서로 허용한 활동을 자연스럽게 발견하고 함께할 수 있지만, 소셜 활동이 필수이거나 클랜이 메인이어서는 안 된다.
4. **즉흥 사진·놀이 미션은 보너스:** 클랜 깜짝 미션과 서버 공통 참여형 보너스로 역할을 제한한다. 이를 핵심 일일 퀘스트로 일반화하지 않는다.
5. **트렌드 형성은 목표가 아님:** 콘텐츠가 자연스럽게 공유될 수는 있으나 이를 억지로 만들기 위한 피드·랭킹·라이브 위치 공유·과한 기기 연동은 범위 밖이다. 외부 트렌드 데이터는 퀘스트 품질에 기여할 때만 도구로 사용한다.
6. **성취의 가시화:** 현실 수행 → 진행 기록·XP/Cash → 보상·마스코트/마이페이지 꾸미기 → 다시 도전하는 경험을 중시한다. 수치·보상은 수행을 대체하지 않는다.

> 당시 '트렌드를 목표로 한다'던 발언은 위 방향 정정으로 우선순위가 바뀌었음. 더 이상 퀘스트북을 인기 콘텐츠로 만드는 것을 출시 성공의 필수 요건으로 간주하지 않는다.

## 6. 이용자 지향 [구상]

> “이 콘텐츠를 수용할 세대는 MZ~Z 및 청소년층이라 생각함.”

친구를 초대하고, 꾸미고, 서로 보여 주고, 단순 회사 업무 외에도 이루고 싶은 목표가 많은 사용자를 염두에 둠. **주요 타깃에 대한 창업자의 가설**이며, 실제 연령별 선호·시장 규모가 조사로 증명됐다는 뜻은 아님.

## 7. 현재 단계에서 확정하지 않는 것

홈에서 퀘스트/마스코트/친구를 몇 퍼센트 노출할지, 어떤 내비게이션을 쓰는지, 색·유리·카드·폰트 등 시각 토큰은 이 문서가 정하지 않음. [OPEN.md](../OPEN.md) 및 향후 웹 프로토타입 합의 대상.
