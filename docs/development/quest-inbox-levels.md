# 수락·거절 알림과 사용자 레벨

첨부 수신함에서 종류/내용/상태의 계층과 행동 위치를 참고한다. 기존 크림색 테마를 유지하고 이모티콘은 제안·진행·완료·거절과 레벨을 구분하는 데 사용한다.

- 앱 알림 시트: 오늘의 제안·진행 중·완료·거절 기록을 표시한다. 미수락 제안에만 수락/거절 버튼이 있고 진행 중이면 상세에서 완료한다. 거절과 수락 후 중단은 구분한다.
- Android 알림: 일괄 건수 안내 대신 퀘스트별 알림에 수락/거절 PendingIntent를 연결한다. 기존 비공개 수신기·알림 채널·진행 중 완료/미루기 경로를 유지한다. 권한이 없어도 앱 안에서 처리할 수 있다.
- 거절은 오늘의 미수락·미완료·미거절 행만 dismissed로 표시하는 조건부 SQL이다. 수락과 거절 중 먼저 성공한 하나만 유효하고 중복 요청은 변화가 없다. 기존 기록과 부모 목표는 삭제하지 않는다. 같은 날 제안을 재생성하지 않는다.
- 개인 레벨은 완료 보상 1 C당 1 XP, 100 XP당 1레벨이다. 레벨 1부터 시작하며 구매 차감과 무관하다. 일일/목표의 실제 완료 보상 합계를 Long으로 계산한다. 연결된 부모의 0 C 보상은 중복 XP가 되지 않는다. 기존 완료 이력도 반영하며 XP를 별도 지급/저장하지 않아 재시작·중복 완료로 추가 경험치가 생기지 않는다.
- 홈·마이에 실제 레벨과 진행량을 표시한다. 타인 임시 프로필은 시연 기록에서 만든 임시 레벨이며 개인 XP를 공유하지 않는다. DB 스키마와 기존 식별자는 유지한다.

검증: 레벨 경계/나머지/음수/큰 누적값 단위 테스트. 거절 중복·날짜·수락 후 거절 차단 Room 계측 테스트를 추가하고 컴파일한다. 사용자 지시대로 기기·에뮬레이터는 실행하지 않으므로 알림 권한·실제 알림 액션·기기 UI 및 Room 계측 실행은 미검증이다.

소스 검토에서 알림 생성 스냅샷과 수락·거절·완료가 경합하면 오래된 제안이 재게시되는 문제를 발견했다. 예약 수신기와 UI의 상태 변경/알림 갱신을 공통 mutex로 직렬화하고 재검토했다. 알림 builder는 내부에서 재잠금하지 않는다. SQLite에서 실제 DAO 거절 SQL의 다른 날짜·최초/중복 거절·수락된 행 보호도 확인했다. SQLite 검증은 Android Room 계측 실행과 구분한다.

최종 검증: assembleDebug·assembleDebugAndroidTest·testDebugUnitTest 성공. 단위 테스트 18개 실패·오류·건너뜀 0개. 레벨 계산 3개와 기존 15개를 포함한다. Room 계측 테스트는 컴파일만 했고 실행하지 않았다. 로그는 개발 환경 `/workspace/levels-verified.log`.
