# UI-001 · 갓생알리미 기술 계승

- 상태: IN_PROGRESS(SEED 조정·개편). INFRA-001의 원격 문서·등록은 반영됨; Node 검증은 독립 미완료이며 SEED 정본 개편을 차단하지 않는다. 요청된 방향은 버튼·타이포 활용, 디자인 완성도와 일관성, 이펙트·알림창·애니메이션 등 갓생알리미에서 익힌 구현/표현 기술의 계승.
- 비목표: 갓생알리미의 화면·브랜드를 그대로 복제하거나 갓생패치의 소셜 퀘스트·도장 마스코트·보상 정체성을 덮어쓰기. 권한·개인정보·동작 감소 등 접근성 경계 보존.
- [갓생알리미 실제 HTML/CSS 기준 4d9a706](https://github.com/jaksim0sec/godseng-alarm/blob/4d9a706aeed572f5aed3e2659c069def3f737e33/app/src/main/assets/index.html)의 표현을 조사했다. 기존 [SEED](../../../seed/INDEX.md) 승인 범위와 [OPEN](../../OPEN.md)의 미결을 비교한다.

## T1 기술 비교 및 계승 기준

버튼 상태·타이포 위계·여백/표면·디자인 일관성·이펙트·알림창/시트·모션을 실제 소스와 시연으로 대조한다. 온보딩 조사 근거는 후속 TODO를 위해 보존한다. 그대로 재사용/갓생패치에 맞게 변경/채택 제외를 구분하고 기존 확정 사항과 충돌을 기록한다. 변경된 정본과 실제 검증 기준을 준비한다.

## T2 공통 UI 표현 및 피드백

T1의 기술 비교를 바탕으로 SEED의 디자인 철학·Foundation·Component·Pattern·토큰 정본을 조정·개편한다. 산출물은 플랫폼에 종속되지 않는 재사용 디자인 규격과 필요한 표현 기술 참고이며, 앱·웹 화면 구현이 아니다. 실제 실행 검증은 미래 구현 작업으로 넘긴다. 아래 1~3차 기록은 과거 웹 후보의 근거로만 보존한다.

- 1차: 기존 공통 버튼 face, 아이콘, Filter Chip의 press/transition 및 native Switch 스타일을 기존 CSS에 추가. 실제 기능·승인 치수/브랜드 값 변경 없음. Switch는 소비 페이지 미연결이며 신규 설정을 만들지 않음. 테스트 2개 추가, 실제 Node/브라우저 실행 NOT RUN.
- 2차: 실제 웹 preview에서 `?design=refined`로 동일 데이터·라우트의 시각 비교안을 실행할 수 있게 연결했다. Root만 큰 제목/높이, Section·Hero·Number의 위계, 일반 Surface 면/곡률, 알림·메시지 시트의 내용 높이와 제목·여백, Dialog·Snackbar 진입 효과를 후보로 구현했다. 새 Page Type/Variant/기능·저장 변경 없음. 기존 D-015/토큰/기본안은 유지. Switch 소비 연결 및 퇴장 모션은 3차에서 처리.
- 3차: refined 메뉴에서 기존 다크 모드를 native Switch에 연결. 저장 키·기능 동일, 입력 포커스와 메뉴 유지. 기존 native dialog close를 지연하지 않고 지원 브라우저에서 display/overlay 퇴장 180ms를 적용, 미지원 환경은 즉시 닫기. Snackbar 퇴장/타이머 취소·동작 감소 대응. 새 기능/저장 구조 없음.
- 검증: 변경 전후 소스·정적 계약을 대조하고 테스트를 추가했다. 실제 Node/브라우저 및 실기기 NOT RUN. 2026-11-27 D-018: 웹 Preview/Lab은 [유물](../../../archive/README.md)로 전환. 추가 웹 구현·비교 렌더 게이트는 범위에서 제외하되 기존 미검증은 PASS로 바꾸지 않는다. 표현 후보·정본·에셋 보존. 이전의 Android 편입 대기 조건은 사용자 정정에 따라 폐기한다. 다음은 SEED의 현재 규격·후보·토큰 정합화 및 과도한 설명 압축이다. T2 종결 아님.

**목표: SEED 조정 및 개편 자체의 완결.** Android 정본 구축은 훗날의 작업이다. 앱/웹 구현·시각 렌더·실기기 검증은 T2 범위 밖이며, 유물은 참고 근거로만 사용한다. 기존 승인과 새 제안의 지위를 보존하고, 새 후보를 사용자 승인으로 소급 표기하지 않는다.

**현재 판정:** IN_PROGRESS / 지속가능. T1 소스 비교는 정적 PASS, 과거 웹 렌더는 NOT RUN이며 추가 웹 검증은 종료 조건에서 제외한다. 현재 T2는 핵심 SEED 정본 개편·경량화 및 후보 토큰 등록까지 반영했다. 다음 행동: 전체 영향 교차 참조·기존 품질 검사/TRACE 정합성 최종 점검 후 종결한다. 실제 앱 이관/적용/실기기 검증은 후속 TODO에 둔다. Android 미편입은 더 이상 병목이 아니다.

**범위 변경:** 미착수였던 T3 온보딩은 사용자 요청에 따라 UI-001에서 제외하고 [전역 TODO](../../core/TODO.md)로 이관한다. 기존 조사 근거와 권한/접근성 원칙은 보존한다. T3 완료를 의미하지 않으며 번호를 다른 기능에 재사용하지 않는다. UI-001은 T1/T2 두 단계만 유지한다.
