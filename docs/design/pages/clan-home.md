## 01 Page Intent

| 필드 | 결정 |
|---|---|
| 유형 | 글로벌 (Root, 클랜 탭 활성) |
| 과업(동사) | 이번 주 클랜 공동 기록과 동료 활동을 읽고 행 단위로 응원한다 |
| 목적 | 공동 기록을 클랜 정체성과 연결하고 즉시 동료에게 반응한다 |
| 주연 1개 | 공동 기록 620 / 1,000 (O-PROGRESS 대표값) |
| 대표 행동 1개 | 사람·활동 행 안의 응원 |
| 핵심 데이터 | 클랜 이름·깃발, 공동 현재/목표(620/1000), 공유된 활동 행 |
| 보조 데이터 | 참여 인원 6명 1회, 마감, 주간 순위 12위↑3, 보상 미리보기 링크 |
| 다른 화면 책임 | 보상 구성→#clan-reward, 전체 멤버→#clan-my, 기록→#clan-record, 소식 전체→#clan-activity |
| 제외 목록과 이유 | 광고 Hero·중복 카피·상자 대형 A1·아이템 3타일·동일 목적 링크 2개는 공동 기록과 사람 활동을 밀어내므로 제거; 가입 중 공개 클랜 탐색은 제외 |

**G1:** 주연 1개/대표 행동 1개/제외 목록 확보. 구현 후 첫 뷰포트 실측으로 재판정한다.

## 02 콘텐츠·행동 인벤토리

- 가입 상태: 깃발·클랜명·8명은 정체성; '6명'은 공동 기록 부가 정보에 **한 번만** 유지. 620/1000(주연)과 380(파생)·일요일(마감)은 한 소스.
- 기존 Reward Hero + A1 57% 확대·꾸미기 3타일은 홈에서 삭제하고 보상 상세로 이동.
- 기존 사람 Grid를 O-PERSON-ACTIVITY **Flat 행**으로 교체, 응원 State와 링크는 원래 데이터 연동 보존.
- 주간 순위와 클랜전/상점은 보조 Flat Link; 별도 Hero 아트·High CTA 없음.
- 미가입 상태: 가입/생성에 독립적인 유도 Intent, 대표 행동 '클랜 만들기' High 1개, 초대 Medium, 공개 탐색은 유지.

**G2:** 데이터 중복은 같은 수치가 서로 다른 맥락에서 쓰일 때만 허용하며 실제 화면에서 횟수 검사한다.

## 03 객체·정보 구조

- Joined: Identity(깃발/이름) → O-PROGRESS(대표값·Track·마감) → O-PERSON-ACTIVITY(활동+응원) → 순위/탐색 Link.
- Guest: 간단한 소개 → 생성 High, 초대 Medium → 기존 공개 클랜 탐색. 개인정보를 공개하거나 실제 가입 완료 주장 금지.

**G3:** O-ITEM/O-PROGRESS/O-PERSON-ACTIVITY 슬롯과 대표 클릭 대상 및 독립 행동을 검증한다.

## 04 선택·배제 근거

- 채택 C-LIST Flat/Inset Divider, C-STATUS default10, C-TEXT Display, O-PERSON-ACTIVITY 행.
- 배제 C-SURFACE Reward Hero(홍보 목적 아님), 물체 Grid(사람 객체 아님), 별도 High CTA(응원이 대표), 중복 보상 링크.

**G4:** 모든 핵심 표현에 대해 채택과 배제 후보를 함께 기록한다.

## 05 시각 위계

- 주연 공동 수치는 첫 390×844 뷰포트 및 사람 행 위에 있고 Hero 문구보다 강해야 한다. Time/Meta는 낮은 Caption, 사람 Identity는 Body. 우선순위가 뒤집히면 G5→G1 복귀.

**G5:** 390×844 첫 뷰포트 실제 Chromium 위치 및 보조 대비로 판정하며 단순 스타일 선언은 통과 근거가 아니다.

## 06 구현·회귀

- 기존 PreviewClan 가입 상태 토글/응원/깃발 마스코트 원본 유지. 기존 클랜 이너 페이지 링크의 목적지는 변경하지 않음.
- Root 5탭 현행 시연 구조 보존, 신규 기능·라우트 0.

**G6:** 공통 토큰, 바텀바, 모든 기존 버튼·탭·응원·초대·마스코트 조합을 실제 실행한다.

## 07 검증·반례·복귀

- **현재 상태: 구현 전 설계 기록**. G1~G6은 설계 후보이며 구현 성공이라고 단정하지 않는다. 렌더/계산스타일/인터랙션 결과는 P3 Actions 실행 후 기록.
- G7 판정 축: 실행 / 규격 / 객체·조합 / 목적 / 행동·회귀.
- 실패 발생 시 실패한 Gate로 복귀한다. 실기기 Android·TalkBack·실제 A2 아트는 범위 밖이며 미검증.
