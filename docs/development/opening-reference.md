# 앱 오프닝

- 2026-11-03 제공 시안: 전체 #e0412f 배경, 중앙의 흰 정면 도장, 하단 흰색 갓생패치, 흰 시스템 바 아이콘.
- 기존 `mascot_face_stamp.png`를 그대로 사용한다. Compose의 흰색 SrcIn tint로 알파/도장 질감을 보존한다. 얼굴 파일과 액세서리는 수정하지 않는다.
- 420ms 동안 94→100% 확대와 60→100% 불투명도 변화, 총 1초 뒤 홈으로 180ms 전환한다. 반복 애니메이션은 없다. 시스템 애니메이션을 끄면 오프닝을 즉시 마친다.
- 초기 실행에서만 표시한다. 화면 재생성은 저장된 표시 상태와 만료 시각을 사용한다. 백그라운드 복귀에는 반복하지 않는다.
- Android 12 이상 기본 스플래시와 이전 버전 시작 배경도 같은 색/흰 이미지로 맞춘다. 플랫폼이 스플래시 아이콘 크기를 제어하므로 Compose 화면과 크기가 완전히 같지는 않을 수 있다.
- 체크리스트/알림/DB 기능은 기존 화면으로 연결한다. 기존 패키지·서명 설정은 바꾸지 않는다.
- 빌드와 소스 확인을 수행하며 실기기 초기 실행·회전·상태 표시줄·홈 전환은 별도 검증이 필요하다.
