# 홈·퀘스트·챕터 시연

기준: 2026-11-02 제공된 네 번째 이미지(홈 로비 / 퀘스트 일지 / 챕터 공략 지도).
현재 홈의 일반 안내 카드와 이전 퀘스트 목록을 이 구성으로 교체한다.

- 홈: 프로필·클랜·실제 캐시 → 큰 제목과 기존 아바타/상자 → 클랜 진행 → 이어하기 → 인기 퀘스트 → 실제 일일 미션 → 클랜 모집.
- 퀘스트: 빨간 선택 밑줄, 메인/일일/완료, 전체/개인/클랜 필터, 미션 상태 트리, 챕터 상자 경로, 새 목표.
- 챕터: 상세 헤더, 어두운 지도와 노란 점선, 빨간 완료 체크, 잠긴 다음 미션, 현재 미션과 시작 버튼.
- 동작: 시작 → 직접 실천 후 완료 → 다음 미션 해금 → 챕터 해금 → 꾸미기 선택. 중복 완료/수령 금지.
- 예시 목표와 보상은 `patch_quest_preview`에 별도 저장한다. 기존 Room 목표, 실제 C, 실제 꾸미기 보관함을 수정하지 않는다. 화면 하단과 보상 화면에 시연을 명시한다.
- 실제 목표 만들기/기존 목표 상세/일일 수락·완료는 기존 로컬 기능을 연결한다. 완료 탭에서 과거 일일 상세도 볼 수 있다.
- 기존 실제 캐시와 내 목표는 유지한다. 시안의 예시 참여 인원은 시연으로 표기한다.
- 기존 아바타·상자 이미지만 재사용하며 얼굴/액세서리 데이터는 변경하지 않는다. 새 실사 이미지나 책 표지는 생성하지 않는다. 이후 표지가 제공되면 책 기호 영역을 교체할 수 있다.
- 새 아이콘은 `assets/icons/svg`의 24×24 / 1.8 stroke / round cap·join SVG를 원본으로 등록하고 `tools/sync_svg_icons.py`로 Android 리소스를 생성한다.

검증: 상태 전이 단위 테스트, APK 빌드, 소스 차이 확인. 에뮬레이터·실기기는 실행하지 않는다.
키보드/제스처/실제 기기의 줄바꿈·색·간격과 재실행 저장 복원은 실기기 검증이 필요하다.
