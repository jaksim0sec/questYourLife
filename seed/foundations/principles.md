# 표현 철학과 추출 경계

## 목적
현실의 행동 → 성취 → 꾸미기·관계라는 제품 경험을, 읽기 쉬운 인터페이스와 풍부한 보상 아트로 표현한다. 제품 정체성 정본은 [VISION](../../docs/product/VISION.md), 결정 정본은 [DECISIONS](../../docs/DECISIONS.md)이다.

## 보존할 시각 문법
- 중립적인 일상 UI 위에 붉은 도장 마스코트와 보상 물체가 정체성을 만든다. 모든 면을 붉게 물들이지 않는다.
- 제목은 충분히 굵고, 본문·부가 정보는 명도와 크기를 단계화한다. 전체 font-weight를 일괄 낮춰 정돈하지 않는다.
- 표면은 부드럽고 둥글며 간격은 규칙적이다. 경계는 그룹의 의미가 있을 때만 둔다.
- 보상 물체는 촉감·부피·광원·수집 욕구가 느껴진다. 작은 정보 아이콘은 단순한 선으로 읽힌다.
- 소셜 정보와 성취 기록은 같은 행·타이포·이미지 프레임 문법을 공유한다. 마스코트·프로필은 장식 부속품이 아니다.

## 설계 감사 우선순위
같은 컴포넌트가 여러 화면에서 다르게 나올 때는 **새 Variant보다 기존 규칙 교정이 우선**이다. 각 항목을 Keep / Refine / Merge·Remove / Split / Add로 분류한다. 기존 버튼·목록·탭·패턴의 디자인 완성도는 확정된 사실이 아니므로 재검토 대상으로 둔다.

S2-08(밝은 클랜/마이/꾸미기)을 일상 UI의 우선 시각 참고, S2-05/07을 콘텐츠 탐색 및 다크 후보, S2-03/06을 입체 일러스트의 표현 참고로 활용한다. S2-01은 버튼 강조 후보, S2-04는 반례, S2-02는 작동하는 시연을 만드는 방법론에만 사용한다. 8장 원본은 R-INPUTS에서 각각 식별한다. 이 우선순위는 **사용자 승인된 색·크기·화면 배치**가 아니다.

## 교정 원칙
일반 버튼은 단색이며 명확한 중요도를 갖는다. 과한 그라데이션·광택·외곽 발광을 제거한다. 내부 콘텐츠를 줄여 필요한 패딩을 먼저 확보한다. 정보가 보조 역할이면 그림·문자·표면도 함께 절제한다. 중요도 부족을 굵기·크기·강한 색을 모두 올려 해결하지 않는다.

## 전역화하지 않을 것
컨셉의 문구·정확한 배치·탭 수·콘텐츠 개수·랭킹 값·기간·XP·보석·시즌 패스·레이드·가격은 시드의 기능 요구가 아니다. REF-003의 보라색과 REF-002의 형광색은 이벤트/콘텐츠 표현 후보이며 새 브랜드색·경제·게임 모드를 뜻하지 않는다.

## 근거와 지위
- 직접 관찰: 밝은 화면과 어두운 화면에 공통된 도장 얼굴, 강한 제목, 둥근 중립 면, 입체 보상. 확신도 high.
- 사용자 지시 U-01/U-02: 감성 유지, 통일성·계층·버튼·패딩 교정, 일반 UI 장식 제한. 이 방향은 명시 지시다.
- 설계 제안: 이후 문서의 토큰·정량 비례·미노출 상태. 승인 상태 proposed.
- 최종 테마, 하단 목적지, 전역 색 수치, 글래스, 실제 동작은 [OPEN](../../docs/OPEN.md)에서 별도 판단한다. 이 문서가 승인 기록을 대체하지 않는다.

## 영향
새 컴포넌트의 필요성을 먼저 기존 슬롯·변형·패턴으로 검토한다. 데이터 이름만 다르면 새 컴포넌트를 만들지 않는다. 같은 동작·강조·크기의 조합이 여러 화면에서 다르게 보이면 로컬 예외보다 정본을 고친다.
