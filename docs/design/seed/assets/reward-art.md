# 보상 아트와 마스코트 표시

## 유지할 표현력
보상은 부피·재질·받침 그림자·현실적인 패션 소품을 통해 '받고 소유하는 느낌'을 준다. 단순한 붉은 도장 얼굴과 입체적인 모자·헤드폰·코인·상자의 차이를 억지로 같은 평면 재질로 만들지 않는다. 마스코트의 얼굴 정체성·장착 기준은 [AVATAR](../../../product/AVATAR.md)와 기존 실제 에셋을 따른다. 이미지 속 변형 얼굴을 신규 정본으로 재제작하지 않는다.

## 표현 레벨
| 레벨 | 용도 | 허용 표현 | 억제 |
|---|---|---|---|
| A1 작은 진열 | 목록·보관함·썸네일 | 중립 프레임, 한 물체, 부드러운 접지 그림자 | 글로우·파티클·리본·배경 광선 |
| A2 콘텐츠 강조 | 한정 배너·주요 소개 | 맥락 있는 장면·광원·제한된 포인트 | 주변 일반 UI까지 금속·네온 적용 |
| A3 획득·기념 | 사용자가 명시적으로 연 보상 장면 | 금속·빛·리본·입체감·선택적 짧은 연출 | 자동 반복 연출·기능 없는 받기 버튼 |

## Asset Presentation
- 같은 진열 모음은 시점·광원 방향·물체의 상대 점유율을 맞춘다. 따뜻한 좌상단 key light + 부드러운 바닥 그림자를 제안하지만 이미지 전체의 모든 장면이 동일 광원이라고 주장하지 않는다.
- 물체는 Image Frame 안에서 contain, 프레임 각 변 안전 여백은 약 10–15%를 검토 출발점으로 제안한다. 실제 bounding box·모자 돌출부·축소 가독성으로 보정한다.
- 질감은 작은 크기에서 형태를 읽을 정도로 유지한다. 미세 입자·반짝임 때문에 실루엣이 무너지지 않게 한다.
- 코인·꾸미기 아이템의 고유색은 일반 UI 색 토큰이 아니다. 브랜드 빨강·캐시 금색·시즌 보라를 한 전역 palette 역할로 합치지 않는다.
- 배경이 있는 illustration은 cover할 수 있으나 얼굴·핵심 물체·실제 텍스트의 안전영역을 확보한다. 생성 이미지에 포함된 글자는 제품 라벨·가격·상태의 정본이 아니다.

## 모션·상태·접근성
수령 가능/처리 중/완료/잠김은 C-STATUS/C-SURFACE/P-STATES의 실제 라벨로 전달한다. 아트 자체가 값·상태를 단독 소유하지 않는다. 무모션·저성능 대체는 정적 아트와 결과 텍스트다. 작은 아이템과 획득 장면에 같은 고해상도 연출을 무조건 쓰지 않는다. 최종 포맷·해상도·압축·메모리 예산은 실제 리소스 확인 후 결정한다.

## 제외·미결
REF-003의 보석·XP·시즌 패스·유료 가격·레이드·음식 보상은 표현 연구 자료다. 제품 기능·경제·보상 종류로 채택하지 않는다. 컨셉의 장식은 시스템 위계·패딩보다 우선하지 않는다. 신규 에셋 생성·기존 파일 변경·실제 장착 좌표 조정은 이번 작업에 포함하지 않는다.

## 근거·영향
입체감과 도장 얼굴의 조합은 반복 관찰 high, 사용자 표현 보존 요구 U-02. 광원·안전여백·레벨 규칙은 proposed. 모든 이미지가 같은 렌더 파이프라인으로 제작됐다는 제작 메타데이터는 없다. 아트 교체 시 프레임·선택 상태·타이포·CTA 가독성을 함께 확인한다.
