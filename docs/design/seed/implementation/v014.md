# v0.14 · User-supplied icon source (56)

## Authority & scope

**Current icon-source authority is [the 56-file user-provided pack](../../../../assets/icons/soft/v0.14/README.md).** It supersedes the assistant's previous 37-icon v0.14 drafts *without changing stable paths*. The four sidebar screenshots remain design context only. No HTML previews are in source control.

Original ZIP: `soft-icons-v014-56.zip`, 2026-11-05. Unmodified SVGs: 32 core Outline + 5 active Fill + 19 additional Outline. [Machine-readable manifest](../../../../assets/icons/soft/v0.14/manifest.json). Source `STYLE.md` and `QA.json` are archived beside the SVGs.

## Design contract

- `viewBox="0 0 24 24"`, width/height 24, `stroke="currentColor"`, default `fill="none"`, `stroke-width="1.8"`, rounded ends/joins.
- Touch areas belong to parent Buttons/Navigation: >=48dp where required. Avoid inflating the icon glyph itself to create hit area.
- Semantic color from parent. No fixed red in default geometry; theme-aware active state controlled by caller.
- `-fill.svg` uses independent paths for home, chat, users, user, and check-circle. Other icons remain Outline unless a separate Fill is designed and approved.
- Optical scaling varies by context as specified in [C-SVG](../components/svg-icon.md); do not stretch/rewrite viewBoxes for larger contexts.

## Mapping and caveats

- The app's clan navigation icon is the previously approved **compass**, not `users.svg`. Do not replace `main`'s nav SVG/VectorDrawable automatically. The app's goal/quest tab also has existing navigation decisions; mapping requires explicit review.
- `coins` is a generic icon. Actual cash rendering uses existing raster art, not a substitute glyph.
- `check-circle-fill` uses SVG masking; the simple Android SVG converter does not support `mask` natively. Convert with a tested equivalent vector strategy, retaining an intact fill and check cutout.
- `settings.svg` is a 3.9KB user-supplied detailed outline. Keep source unchanged; optimize only in a future approved change with visual diff.
- Visual note to verify on-device: `more.svg` has relatively small three strokes; ensure it is visibly legible against dark/bright backgrounds.

## Validation

- Source Git tree holds all 56 files. Every Git blob SHA-1 equals original ZIP SVG content (full set verified via aggregate checksums).
- Local parse and CairoSVG 24px rasterization passed 56/56 with nonempty, in-bounds results.
- Android VectorDrawable build, 24dp pixel QA, actual tab behavior, dark-mode visual QA, accessibility, navigation mapping: **not done**. The HTML prototype is not the source of truth and no Android code was changed in this commit.

## Agent workflow

1. Read [INDEX](../INDEX.md) and [C-SVG](../components/svg-icon.md).
2. Use the names in [manifest](../../../../assets/icons/soft/v0.14/manifest.json) to select an actual SVG file. Do not reinterpret or create a library lookalike.
3. Match context and existing app decisions. For Compose SVG migration use an explicit converter and verify mask support.
4. Generate/check VectorDrawables and preview screens, then compile and test before calling native implementation complete. Keep this docs-only source change separate from application deployment.
