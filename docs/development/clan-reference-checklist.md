# 클랜 시연 재현 — 대상과 에셋 상태

2026-11-02. 이번 요청의 기준은 사용자 메시지의 **3번 단독 클랜 화면**이다. 기존 ClanPage의 카드와 정보 구조를 보존하지 않는다. 다른 본문 페이지는 개편 대상이 아니며, 공유 헤더·하단 탭은 제공 SVG로 교체한다. 모자/헤드폰 등 아바타 착장 합성은 제외한다.

## 기준 화면의 순서

1. 좌측 클랜 제목, 우측 알림·메뉴. 동일 헤더 기준선.
2. 연두색 깃발, 느슨한 갓생단/멤버 수, 우측 테두리 초대 버튼.
3. 짙은 무채색 공동 상자 영역: 좌측 두 줄 제목·주간 진행·노란 진행 막대·수치·보상 설명, 우측 기여 인원 배지·금색 상자.
4. 흰색 '이번 주 함께 쌓은 기록' 영역: 착장 없는 원본 얼굴 아바타 4개.
5. 흰색 '멤버 기여도' 영역: 기간 필터, 순위·얼굴·닉네임·획득 캐쉬, 내 행의 연한 회색 강조.
6. 연회색 주간 순위 요약: 큰 순위·빨간 상승 표식·우측 안내와 이동.
7. 제공 SVG를 쓰는 동일 너비 5탭. 클랜 선택 상태.

화면 크기에 맞춘 여백·타이포·모서리·카드 높이·정보 밀도·기준선까지 비교한다. 시연 그림 전체를 배경이나 잘라낸 버튼으로 사용하지 않는다. 가상 클랜 정보는 임시 서비스에서 제공하며 실제 서버 응답으로 주장하지 않는다.

## 원본 등록과 확인 결과

- 사용자 SVG 12개를 `app/src/main/assets/icons/svg`에 원본 그대로 등록했다.
- `tools/sync_svg_icons.py`가 같은 도형·선·색상을 Android VectorDrawable로 변환한다. 탭과 헤더에서 라이브러리 대체 아이콘을 제거하고 이 리소스에 연결했다. 활성 아이콘의 흰색 세부를 보존하기 위해 일괄 tint를 사용하지 않는다.
- 별도 소스 검토에서 경로/색상 변환과 바인딩의 알려진 결함은 발견되지 않았다. 기기 렌더링 확인과는 구분한다.
- 묶음에는 **금색 상자 이미지와 마스코트 래스터 파일이 없다**. 메시지에 표시된 얼굴은 시각적으로 확인했지만 앱에 넣을 고해상도 원본 파일은 ZIP에 포함되지 않았다.
- 제공 `nav-active-clan.svg`/`nav-inactive-clan.svg`의 **나침반**은 사용자가 새 클랜 아이콘으로 확정했다. 이전 시연의 사람 아이콘보다 최신 요청이 우선한다.

## 최신 요청에 따른 구현

사용자는 이미지 파일을 SVG ZIP과 묶을 필요가 없다고 명시했고, 황금 상자는 보류하고 자리만 남기도록 지시했다. 따라서 더 이상 상자/수정 SVG를 선행 조건으로 요구하지 않는다.

- 클랜 본문을 기존 generic 카드에서 교체했다. 깃발·초대 / 어두운 공동 보상 / 네 얼굴 기록 / 3행 기여도 / 주간 순위의 구성과 밀도를 기준으로 재작성했다.
- 황금 상자 영역은 오른쪽 아래 126dp 높이의 투명 슬롯으로 남겼다. 가짜 상자·대체 일러스트·이미지 미제공 문구를 그 자리에 넣지 않는다. 아바타 착장은 하지 않는다.
- 기존 도장 얼굴 리소스를 작은 아바타로 사용한다. 메시지에 표시된 새 고해상도 이미지 바이너리를 앱에 등록했다고 주장하지 않는다. 별도 원본 파일이 실행 환경에 전달되면 아바타 리소스만 교체할 수 있다.
- `ClanPreview`와 임시 게이트웨이가 예시 클랜 상태를 제공한다. 8명/6명 기여/780점/12위/3단계 상승은 시연용 데이터이며 내 개인 캐쉬 원장에 들어가지 않는다. 강조된 이모리 행도 예시 프로필이다.
- 기간 선택은 멤버 기여도만 전환한다. 초대 버튼은 예시 코드 복사와 Android 공유 선택기를 제공하며 실제 서버 가입으로 오인하지 않도록 시트에서 안내한다. 순위 요약은 주변 순위의 예시 목록을 보여준다.
- 나침반 및 헤더/탭 아이콘은 앞서 등록한 사용자 SVG 그대로 유지한다. DB·계정·기존 개인 퀘스트 데이터는 변경하지 않는다.

검증 명령과 실제 화면 비교 결과는 이번 작업의 최종 실행 후 아래에 기록한다. 소스 구현·빌드 성공과 시연 대비 렌더 검증은 구분한다.

## 검증 및 표시 이름 변경

- 사용자 최신 지시에 따라 한국어 앱 표시 이름을 **갓생패치**로 변경한다. main/debug 런처 이름, 화면 제목, 접근성 설명, 알림·공유 문구와 현재 기획 원본에 반영한다. applicationId, namespace, Room DB 이름과 서명 설정은 유지한다.
- 클랜 본문과 공유·기간·순위 동작의 독립 소스 검토에서 발견한 항목을 수정했고, 재검토에서 알려진 중요 소스 문제는 발견되지 않았다.
- 사용자가 직접 기기 검증을 맡겠다고 명시했으므로 에뮬레이터 검증은 중단했다. 시연 대비 최종 렌더링 동일성·터치 동작을 기기에서 검증 완료했다고 주장하지 않는다.
- 최종 빌드·단위 테스트 결과는 커밋 전 확인한다. 별도 서버·인증·DB 마이그레이션·캐쉬 원장 변경은 없다.

최종 확인: APK 빌드 성공, 단위 테스트 6개 통과(실패/오류 0), 서명 검사 성공, APK 표시 이름 `갓생패치 미리보기`와 기존 패키지 `com.questyourlife.app.preview` 유지 확인. 기기 렌더·동작 검증은 사용자에게 맡긴다.

## 실기기 비교 피드백 반영 (후속 수정)

사용자가 제공한 좌/우 비교를 기준으로 분석했다. 왼쪽의 문제는 주요 제목 크기 하나보다 보조 정보의 상대적인 약함, 큰 필터, 작은 실제 아바타 잉크 영역, 흐린 탭 아이콘, 짧은 화면에서 하단 순위가 밀려나는 조합이었다.

- 원격 main의 상자 4종(`box_gold`, `box_oak`, `box_paper`, `box_taped`)과 `mascot_face_stamp.png`를 확인했다. 이번 클랜에는 `box_gold.webp`를 우하단 실제 이미지로 연결한다. 이전의 '상자 자리 비움' 지시는 이번 제공 에셋 연결 요청으로 대체된다. 다른 3종의 사용처는 임의 추가하지 않는다.
- **모든 사용자 아바타**는 정확히 `R.drawable.mascot_face_stamp`를 사용한다. 공용 MascotArt도 새 원본을 사용하고 DM 친구의 첫 글자 아바타도 교체했다. 아바타에 모자나 다른 꾸미기를 합성하지 않는다.
- 공동 상자의 제목은 ExtraBold, 설명은 13sp, 진행 수치는 12sp, 보상 설명은 11sp로 상대 강조를 조정했다. 불필요한 제목 아래 spacer와 반복 간격을 제거하고 상자/텍스트 영역 폭을 분리했다. 진행 막대는 가용 폭과 글자 배율에 맞춰 줄어든다.
- 기간 필터의 시각 높이를 30dp로 줄이고 카드 상단 여백을 줄였다. 기여도 이름/수치는 16sp, 아바타는 46dp, 활동 얼굴은 60~64dp로 강화했다. 원본 얼굴의 실제 잉크 영역을 줄이던 원형 배경/추가 안쪽 여백을 제거했다.
- 내용 높이 650dp 미만이면서 기본 글씨 배율일 때 행/카드 세로 간격을 압축한다. 큰 글씨에서는 텍스트를 강제로 축소하지 않고 스크롤을 유지한다. 진행 설명은 좁은 폭이나 큰 글씨에서 두 줄을 허용한다.
- 네비게이션은 원본 SVG 도형을 유지하며 아이콘 24→30dp, 라벨 11→12sp, 비활성 선 #8e8e93→#222222, 선 두께 2→2.2로 변경했다. SVG를 수정한 뒤 생성기를 실행했고 XML만 따로 손대지 않았다. 활성 아이콘의 흰 세부는 그대로 보존한다.
- 에뮬레이터는 사용자 요청대로 실행하지 않는다. 이번 확인은 사용자 비교 이미지의 분석, 코드/에셋 검토와 빌드 검사이며, 수정 후 실기기 동일성은 사용자가 확인한다.

후속 수정 최종 검사: APK 빌드 및 단위 테스트 6개 통과(실패/오류 0), 서명 검사 통과, APK 내부의 금색 상자/새 얼굴 파일 포함 확인. 제공된 두 이미지의 RGBA 투명도도 확인했다. 독립 소스 검토에서 알려진 중요 결함은 발견되지 않았으며, 실제 수정 화면 검증은 사용자에게 맡긴다.

## 멤버·초대·가독성 후속 조정

- 사용자가 요청한 현재 이름은 `갓생패치`이며 debug 런처에서도 미리보기 접미사를 제거한다. 앱 패키지·서명·데이터 식별자는 변경하지 않는다.
- 사용자가 추가한 초대 아이콘의 원본을 `invite.svg`로 바꾸고 생성된 `ic_patch_invite` 벡터를 초대 버튼에서 사용한다. 내비게이션 아이콘은 30→28dp, 비선택 아이콘은 0.7 불투명도로 조정한다.
- '우리 클랜의 멤버들'은 실제 예시 멤버 목록을 최대 10명까지 표시하는 가로 스크롤 행이다. 얼굴을 64/68dp로 조금 키우고 간격을 6dp로 좁혔다. 멤버 이름은 접근성 설명에 반영한다.
- 비중이 작던 클랜 이름과 보조 텍스트, 기여도·상자·순위 영역의 글자 크기/굵기/대비를 강화한다. 목록 데이터는 가상 게이트웨이에 보관하고 상위 세 명만 기여도에 표시한다.
- 실기기/에뮬레이터 실행은 사용자의 지시에 따라 수행하지 않는다.

최종 검증: APK 빌드·서명 검사 성공, 단위 테스트 7개 통과(기여 인원/합계 불일치 회귀 테스트 포함), APK 런처 이름 `갓생패치` 및 기존 preview 패키지 식별자 확인. 실제 화면 확인은 사용자가 진행한다.

## 실기기 추가 피드백

- 글자 크기를 무조건 키우지 않는다. 클랜 이름은 20sp/ExtraBold, 멤버 수는 12sp/SemiBold로 조정하고, 기여도 이름·수치도 15sp/Bold로 강조한다. 공동 상자 보조 문구는 작은 크기를 유지하면서 굵기를 높였다.
- 상자 이미지는 오른쪽 여백을 8→16dp로 늘려 조금 왼쪽으로 이동했다. 텍스트 영역도 함께 줄여 두 영역이 겹치지 않도록 했다.
- 기본 화면에는 실제 목록에서 최대 네 명을 **온전히** 표시한다. 화면이 좁으면 얼굴 크기를 가용 폭에 맞춰 줄인다. 멤버 영역을 누르면 전체 보기에서 최대 10명을 표시한다. 데이터의 멤버 수를 4명으로 제한하지 않는다. 기존의 가로 스크롤 8명 표시 계획보다 이번 사용자 수정이 우선한다.
- 실제 화면 확인은 사용자가 담당하므로 에뮬레이터는 실행하지 않는다.

검증: 빌드 및 단위 테스트 7개, APK 서명 검사 통과. 독립 소스 검토에서 발견한 좁은 폭·큰 글씨의 진행 수치 잘림은 진행 막대와 수치를 세로로 전환하도록 수정하고 재검토했다. 에뮬레이터와 실제 기기는 사용자 지시에 따라 실행하지 않았다.

## 하단 내비게이션과 글자 굵기 조정

- 사용자 후속 요청에 따라 고정 하단 바 높이 64→58dp, 아이콘 28→25dp, 아이콘·라벨 간격 4→3dp, 라벨 12→11sp로 함께 줄였다. 시스템 내비게이션 인셋은 별도로 유지하며 탭의 터치 영역은 바 전체를 사용한다.
- 비활성 아이콘과 텍스트 모두 같은 #222222와 0.55 불투명도를 사용한다. 활성 아이콘·라벨은 같은 #e0412f을 사용하고 아이콘 내부의 흰색은 유지한다. SVG 원본에서 활성 선 두께 2→1.8, 비활성 2.2→2로 조정 후 Android 벡터를 재생성했다.
- 클랜 제목·마스코트 기록/기여도 제목·상자 제목·멤버명/기여도·보조 정보는 글자 크기는 유지한 채 FontWeight를 높였다. 런타임의 실제 서체 매핑과 화면의 최종 시각적 차이는 사용자 기기에서 확인한다.
- 사용자 요청에 따라 에뮬레이터/기기 실행은 하지 않는다.

검증: APK 빌드·서명 및 단위 테스트 7개 통과. 별도 소스 검토에서 아이콘·글자 색/불투명도, 선택 상태, 58dp 터치 영역과 SVG 벡터 변환을 확인했다. 실제 기기 렌더링은 사용자 지시에 따라 실행하지 않았다.
