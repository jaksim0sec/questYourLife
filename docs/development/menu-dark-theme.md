# 메뉴 재구성과 화면 테마

참고 사진의 구분 제목/행/구분선/설정 구조를 기존 앱에 적용한다. 프로필·결제·멤버십·성인 콘텐츠 등 우리 앱에 필요 없는 항목은 넣지 않는다. 목표와 실천(목표 상담/직접 생성/타이머), 기록과 소통(완료 기록/새 쪽지), 앱 설정(화면 테마/알림과 설정)으로 묶는다. 꾸미기는 마이의 기존 동작을 사용하고 기본 체크리스트는 설정에서 유지한다.

신규 SVG는 sparkles/target/history/timer/mail/moon/settings. 24×24, currentColor, 1.8 stroke, 둥근 끝과 연결부다. 원본은 assets/icons/svg, 대응 VectorDrawable은 기존 변환 도구로 등록한다. 변환기는 기존 내비게이션의 중심 확대 g 그룹도 처리하며 알 수 없는 변형은 실패시킨다. 다크 선택 탭은 별도 SVG 변형에서 강조색과 내부 대비색을 바꾸고 같은 도형을 유지한다.

테마는 시스템/라이트/다크를 선택하여 patch_appearance.mode에 저장한다. LocalPatchDark와 의미별 색을 현대 화면 및 기존 상세 화면에 공유한다. 차콜 배경·단계별 표면·밝은 주 텍스트·회색 보조 텍스트·밝은 붉은 강조색을 사용한다. 다크 버튼에는 어두운 onPrimary를 사용하고 노란/연두 배너의 글자는 어두운 색으로 유지한다. 홈/클랜의 어두운 강조 영역과 원본 이미지 색은 반전하지 않는다. 상태바·시스템 내비게이션 아이콘도 테마에 맞춘다. 기존 고급 기본 체크리스트는 자체 다크 테마를 유지한다.

검증 범위: APK 빌드·기존 회귀 테스트·SVG 변환·주요 색 대비 계산 및 별도 소스 검토. 사용자 지시대로 에뮬레이터/기기를 실행하지 않으므로 라이트/다크의 최종 렌더링·시스템 바·테마 재생성·기기 설정 변경 반영은 기기 미검증이다.

최종 확인: assembleDebug·testDebugUnitTest 성공, 테스트 18개 실패·오류·건너뜀 0개. 신규 12개 및 기존 내비게이션 10개, SVG/VectorDrawable 22쌍을 임시 디렉터리에 재생성하여 구조 일치를 확인했다. 주요 대비는 다크 본문 15.99:1, 보조 글자 6.38:1, 다크 버튼 7.21:1, 라이트 버튼 4.96:1, 라이트 보조 글자 4.89:1, 노란 배너 글자 12.46:1이다. 모든 픽셀과 상태를 감사한 결과는 아니다. 별도 소스 검토에서 발견한 퀘스트 카드의 고정 밝은 배경과 흰 선택 표시를 수정하고 재검토했다. 로그 `/workspace/menu-dark-final.log`.
