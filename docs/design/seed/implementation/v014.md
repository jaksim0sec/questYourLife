# v0.14 Icon implementation source

The user designated four actual sidebar icon screenshots as the visual grammar. This iteration replaces **37 icon path geometries**, keeps all stable icon names and 5 explicit `-fill` pairs, and creates **real standalone SVG files**, not just an HTML design mockup.

## Asset path

[`docs/design/seed/assets/icons/v0.14/`](../assets/icons/v0.14/README.md)

## Visual grammar

- 24x24 optical grid. Most silhouettes fit within approx 3.5–20.5 optical bounds.
- 2.15px rounded outlines; single-layer monochrome. No thin hairlines, texture, gradients or fake depth.
- Gentle straight-to-curve transitions. Optical weight and negative spaces are more important than exact numeric line width.
- No unrelated decorations. Distinguishable at rendered 24px.
- Active-state fills are separately drawn, not CSS-filled outlines. White inner cutouts on fills are purposeful.

## Mapping and limits

- `home`: roof/wall/door connected contour; `chat`: circular balloon with integrated tail.
- `users`: two whole people with intact shoulders (alternative clan group representation); `user`: circular profile.
- `book`, `calendar`, `edit`, `clock`, `activity`, `chart`, `settings`, `explore` use the submitted reference's general pictogram proportions.
- `users` must **not** silently replace the Android app's already approved compass clan navigation icon. That is a product decision, not an asset migration.
- Existing v0.13 files are preserved for comparison and rollback. No Android Compose implementation, Room or database change is included.
- When implementing icons natively: decide each icon use-site, generate appropriate VectorDrawable, respect semantic tint and disabled state, audit light/dark contrast and accessibility target. Manual review is required after conversion.
- Preview images and prototype HTML are local QA materials; **not committed**.

## Validation status

- Standalone SVG parse and CairoSVG rasterization passed locally for all 37 source paths. HTML static JS syntax passed; browser navigation was blocked by current environment policy, so interactive browser runtime verification was not obtained.
- GitHub source registration does not imply app deployment or an approved final brand icon set.
