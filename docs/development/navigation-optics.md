# 내비게이션 도형 정렬

홈·쪽지의 외곽을 둥글게 다시 구성하고 다섯 도형의 y 범위를 2.5~21.5로 통일했다. 원형 아이콘은 중심 12/12, 반지름 9.5다. 비활성 획은 1.72, 활성 획은 1.60으로 낮췄다. 기존 중복 확대 g 그룹을 없애고 실제 좌표를 원본으로 관리한다. 라이트/다크 팔레트와 아이콘 의미는 유지한다.

선택 시 계속 1.06배로 남던 크기를 짧은 1→1.045→1 펄스로 바꿨다. 정지 상태에서는 모두 1배다. 바 높이·라벨·간격은 바꾸지 않았다.

검증: SVG 15개를 240px로 렌더링했을 때 활성 외곽 높이는 모두 206px, 비활성은 모두 208px이고 각 상태 내 상단 위치도 같다. 활성/비활성의 2px 차이는 획 차이에 따른 것으로 24 단위 캔버스에서 0.2 단위다. 모든 원본/VectorDrawable 일치를 확인했다. 홈/쪽지 SVG 렌더를 육안으로 확인했고, 별도 소스 검토에서 잘림이나 대응 파일 차이는 발견되지 않았다. assembleDebug 성공(`/workspace/nav-optics-final.log`). 실제 앱의 기기 화면·선택 애니메이션은 사용자 지시대로 실행하지 않아 미검증이다.
