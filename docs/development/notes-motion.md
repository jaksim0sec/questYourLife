# 쪽지 상세 구조·앱 전환·클랜 진행

사용자 첨부 1번의 중복 글로벌 헤더/하단 탭을 없애고 2~4번의 구조를 기존 크림색 테마에 적용한다. 쪽지 목록은 글로벌 탭이고, 대화는 `thread` 세부 경로다. 상세는 상대 아바타/이름과 뒤로가기, 메시지, 하단 입력창만 가진다. 검색 가능한 목록과 ‘새 쪽지’ 상대 선택을 제공한다. 새 그룹 기능이나 실제 전송·읽음 수는 만들지 않는다.

- `DM` 표시는 ‘쪽지’로 통일한다. 내부 저장 식별자는 유지한다.
- 상대 ID는 화면 복원 상태로 저장한다. 뒤로가기는 쪽지 목록으로 돌아오며 퇴장 애니메이션 중에도 기존 대화 내용이 바뀌지 않는다. 모델의 대화가 비어 있는 프로세스 복원에서는 저장된 상대를 다시 연다.
- 메시지는 이름·말풍선·시간 순서, 보낸 메시지는 오른쪽에 정렬한다. 입력창은 IME 인셋 위에서 1~3줄, 전송 버튼은 입력 내용이 있을 때 필드 안에 나타난다. 빈 전송/중복 전송 제한과 실제 Room 저장을 유지한다.
- 탭은 160ms 아이콘 교차 전환·180ms의 작은 선택 확대·색상 변화를 사용한다. 화면은 200~220ms 전환으로 이어지고, 메시지 추가/입력창 크기·공통 금액/패널 상태·꾸미기 착장 전환에도 제한된 애니메이션을 적용한다. 반복·자동 장식 애니메이션은 없다. Compose 기본 애니메이션 시계로 Android의 애니메이션 배율을 따른다.
- 클랜 멤버 제목 옆에 기존 데이터의 `N명`을 표시한다. 패널을 추가하지 않는다. 진행 막대는 회색 전체 트랙 위에 노란색 비율을 연속해서 채운다. 목표 0을 처리하고, 진행률 접근성 값과 260ms 값 전환을 제공한다.

검증 범위: 빌드·기존 정책 테스트·소스 검토. 사용자 지시대로 기기와 에뮬레이터는 실행하지 않는다. 최종 렌더링, 전환 프레임, 키보드·뒤로가기 제스처·앱 재생성은 실기기 미검증이다.

최종 확인: `assembleDebug`·`testDebugUnitTest` 성공, 테스트 12개 실패/오류/건너뜀 0개. 로그 `/workspace/motion-final.log`. 별도 소스 검토에서 새 차단 결함은 발견되지 않았다. 기존의 전역 chatBusy/chatError 때문에 전송 중 대화를 바꾸면 이전 대화의 처리 중/오류 표시가 새 대화에도 나타날 수 있다. 메시지 저장 대상은 요청 시 캡처한 상대 ID를 사용하므로 서로 섞이지 않는다.
