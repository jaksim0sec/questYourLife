# 클랜 시연 재현 — 대상과 에셋 상태

2026-11-02. 이번 요청의 기준은 사용자 메시지의 **3번 단독 클랜 화면**이다. 기존 ClanPage의 카드와 정보 구조를 보존하지 않는다. 다른 본문 페이지는 개편 대상이 아니며, 공유 헤더·하단 탭은 제공 SVG로 교체한다. 모자/헤드폰 등 아바타 착장 합성은 제외한다.

## 기준 화면의 순서

1. 좌측 클랜 제목, 우측 알림·메뉴. 동일 헤더 기준선.
2. 연두색 깃발, 느슨한 갓생단/멤버 수, 우측 테두리 초대 버튼.
3. 짙은 무채색 공동 상자 영역: 좌측 두 줄 제목·주간 진행·노란 진행 막대·수치·보상 설명, 우측 기여 인원 배지·금색 상자.
4. 흰색 '이번 주 함께 쌓은 기록' 영역: 착장 없는 원본 얼굴 아바타 4개.
5. 흰색 '멤버 기여도' 영역: 기간 필터, 순위·얼굴·닉네임·획득 캐시, 내 행의 연한 회색 강조.
6. 연회색 주간 순위 요약: 큰 순위·빨간 상승 표식·우측 안내와 이동.
7. 제공 SVG를 쓰는 동일 너비 5탭. 클랜 선택 상태.

화면 크기에 맞춘 여백·타이포·모서리·카드 높이·정보 밀도·기준선까지 비교한다. 시연 그림 전체를 배경이나 잘라낸 버튼으로 사용하지 않는다. 가상 클랜 정보는 임시 서비스에서 제공하며 실제 서버 응답으로 주장하지 않는다.

## 원본 등록과 확인 결과

- 사용자 SVG 12개를 `app/src/main/assets/icons/svg`에 원본 그대로 등록했다.
- `tools/sync_svg_icons.py`가 같은 도형·선·색상을 Android VectorDrawable로 변환한다. 탭과 헤더에서 라이브러리 대체 아이콘을 제거하고 이 리소스에 연결했다. 활성 아이콘의 흰색 세부를 보존하기 위해 일괄 tint를 사용하지 않는다.
- 별도 소스 검토에서 경로/색상 변환과 바인딩의 알려진 결함은 발견되지 않았다. 기기 렌더링 확인과는 구분한다.
- 묶음에는 **금색 상자 이미지와 마스코트 래스터 파일이 없다**. 메시지에 표시된 얼굴은 시각적으로 확인했지만 앱에 넣을 고해상도 원본 파일은 ZIP에 포함되지 않았다.
- 제공 `nav-active-clan.svg`/`nav-inactive-clan.svg`는 **나침반**이다. 시연은 **사람 모양**이다. 현재 제공 소스를 보존하며, 정확한 재현에는 수정된 두 원본이 필요하다.

## 완료를 위해 필요한 입력

금색 닫힌 상자의 투명 PNG/WebP(권장 512px 이상), 메시지의 마스코트 얼굴 원본을 파일/ZIP으로 전달받아 리소스로 등록한다. 사람 모양 클랜 아이콘의 활성·비활성 SVG도 필요하다. 모자는 이번 범위에서 필요하지 않다. 사용자의 지시에 따라 새 이미지를 생성하거나 도형으로 3D 상자를 흉내 내지 않는다.

이번 커밋은 **아이콘 원본 등록·연결**까지다. 기존 ClanPage 본문은 아직 교체하지 않았으며, 클랜 시연 재현 완료로 표시하지 않는다. 필요한 아트가 확보되면 위 기준대로 본문을 교체하고 실제 Android 캡처를 시연과 비교한다.
