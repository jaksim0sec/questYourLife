# Page Intent와 섹션 목적

## 현행 계약

페이지당 9필드는 반드시 기재한다: **①유형 ②과업(동사형) ③목적 한 문장 ④주연 정확히 1개 ⑤대표 행동 정확히 1개 ⑥핵심 데이터 ⑦보조 데이터 ⑧다른 화면 책임 ⑨제외 목록과 이유(1개 이상)**. 목적을 '보여준다'나 '확인한다'로 끝내면 불합격. 대표 행동은 High CTA를 요구하지 않는다.

### 콘텐츠 목적 5종

| 목적 | 우선 표현 | 아트 | 배제 | 클릭 |
|---|---|---|---|---|
| 홍보 | 좁은 가로 이미지 배너 | A2 전용 장면 | 변동 숫자·버튼 문구 래스터화/진행값 포함 | 목적지 있으면 배너 전체 1개 |
| 진행·관리 | O-PROGRESS | 없거나 A1 썸네일 | 홍보 카피/과대 아트 | 상세 Low 1개 |
| 사람·활동 | O-PERSON-ACTIVITY List | 마스코트 아바타 | 타일 Grid/행별 그림자 | 행 + 독립 응원 1개 |
| 탐색·발견 | Media + 제목 + 메타, Filter는 결과 위 | 썸네일 | 결과 안 바뀌는 필터 | 항목 1개 |
| 획득·결과 | 논글로벌 A3 결과 | A3 | 일상 화면에 A3 반복 | 확인 1개 |

**사람·활동**은 보고서 9.3의 기존 4분류에는 없었던 별도 목적이며 이번 r3 권고대로 추가 승인. A1 확대는 A2가 아니다. A2 텍스트 안전 영역과 크롭은 콘텐츠 배치 전에 검증하고 변동 수치는 HTML로 표현한다. 공동 기록과 홍보, 보상 구성, 개봉 결과는 이름이 '보상'으로 같아도 목적이 다르다.

## 이력

- 기존 클랜 Hero는 홍보·진행·탐색을 한 면에 결합한 R-01 반례. 섹션 목적별로 분리해야 한다.
