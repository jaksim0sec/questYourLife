# 언글로벌 프로필·헤더·아바타 조합

뒤로가기가 있고 글로벌 하단 탭이 없는 상세 화면을 ‘언글로벌 페이지’로 부른다. `person` 경로는 다른 사람의 임시 프로필이다. 클랜 얼굴(기본 멤버·기여도·전체 멤버 시트), 쪽지 목록 얼굴, 대화 상대/받은 메시지 얼굴에서 이동한다. 뒤로가기는 들어온 쪽지/대화/클랜 화면으로 돌아간다. 멤버 시트에서 열면 시트를 닫은 뒤 이동한다.

프로필은 마이와 같은 얼굴·이름·클랜 표식·주간 기록·도장 구성이다. 다른 사람의 수치는 이름으로 정해지는 임시 데이터임을 표시하고 개인 캐시 원장을 읽거나 보여주지 않는다. 친구 추가/요청 취소 상태는 `quest_social_preview` 설정에 이름별로 저장한다. 실제 서버 요청이나 친구에게 알림을 보내지 않는다.

쪽지 글로벌·언글로벌 헤더 모두 기존 알림/더보기 아이콘을 사용한다. 상단 더하기와 대화 헤더의 데모 배지는 제거한다. 실제 알림·메뉴 시트로 연결하고, 새 쪽지 상대 선택은 더보기 메뉴에서 연다. 대화가 데모라는 안내는 내용에서 유지한다.

`AvatarComposer.compose(itemId)`는 크기에 독립적인 `AvatarComposition` 렌더 트리를 반환한다. 레이어는 얼굴→착장 순서이며 각 모자/헤드폰/이어버드가 자신의 x/y/width/height 보정값을 가진다. `DressedAvatar`는 반환된 레이어만 해석하는 공통 Compose 조각이다. 모자마다 보정 코드를 화면에 복사하지 않는다. 미등록 착장은 기본 얼굴만 반환한다. 얼굴/착장 PNG와 기존 구매 ID는 변경하지 않는다. 제공 사진의 이름별 착장은 안정적인 시연 매핑을 사용한다.

검증: 빌드·기존 회귀·아바타 조합 계약 테스트. 사용자 지시에 따라 에뮬레이터와 기기는 실행하지 않는다. 최종 모자 위치/크기와 화면·키보드·실제 뒤로가기 동작은 기기 미검증이다.

별도 소스 검토에서 프로필 왕복 시 쪽지 초안/스크롤 소실을 발견했다. 화면별 SaveableStateHolder를 추가하고 대화/프로필별 키로 분리했다. 같은 메시지로 복귀하면 강제 맨 아래 스크롤을 하지 않도록 수정하고 재검토했다. 최종 `assembleDebug`·`testDebugUnitTest` 성공, 기존 12개 및 아바타 합성 계약 3개, 합계 15개 실패·오류·건너뜀 0개. 로그는 개발 환경 `/workspace/people-verified.log`.
