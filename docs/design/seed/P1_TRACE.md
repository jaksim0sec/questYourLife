## 분류 변경 근거

- `6.5`: 관계별 단일 소유를 C-SELECTION 일괄 지정에서 S-PAGE/C-LIST/F-GEOMETRY/O-ITEM 등으로 수정. 원문 숫자·조건은 변경 없음.
- `9.3`: C-SURFACE/C-IMAGE/C-ACTION/C-LIST/C-SHEET의 실제 부품 보강은 P2 Tier 소관이므로 P2로 이동. P1의 INDEX/VALIDATION/Page Intent/5역할은 P1 유지.
- `4.5`: Root·Standard Title 및 Tabs 치수 후보는 실측 결정을 요구하는 P2로 이관. gutter/center 계약은 P1 유지.
- 표 머리와 과거 비교 수치는 **규칙 채택이 아니라 인용·반례 보존**. 실제 화면 충족은 P3/P4에서 별도 검증.

## 검증과 남은 게이트

- `159` P1 입력 행의 책임·근거를 각 행에 1:1로 남겼다. 정본 소유 파일에 제시한 규칙이 실제로 명시된 것은 작업자가 직접 대조했으나, 자동화는 존재·누락을 따로 검사한다.
- 검수자 독립 세션을 요구하는 **T2는 미실시**. T3의 나머지 의미 충돌 감사를 포함해 G-P1 전체는 미통과.
