# UI-001 · 갓생알리미 기술 계승

- 상태: BLOCKED(실제 Android 기반 편입 대기). INFRA-001의 원격 문서·등록은 반영됨; Node 검증은 독립 미완료로 남기며 이 작업의 디자인 조사/격리 CSS 변경을 차단하지 않는다. 요청된 방향은 버튼·타이포 활용, 디자인 완성도와 일관성, 이펙트·알림창·애니메이션 등 갓생알리미에서 익힌 구현/표현 기술의 계승.
- 비목표: 갓생알리미의 화면·브랜드를 그대로 복제하거나 갓생패치의 소셜 퀘스트·도장 마스코트·보상 정체성을 덮어쓰기. 권한·개인정보·동작 감소 등 접근성 경계 보존.
- [갓생알리미 실제 HTML/CSS 기준 4d9a706](https://github.com/jaksim0sec/godseng-alarm/blob/4d9a706aeed572f5aed3e2659c069def3f737e33/app/src/main/assets/index.html)의 표현을 조사했다. 기존 [SEED](../../../seed/INDEX.md) 승인 범위와 [OPEN](../../OPEN.md)의 미결을 비교한다.

## T1 기술 비교 및 계승 기준

버튼 상태·타이포 위계·여백/표면·디자인 일관성·이펙트·알림창/시트·모션을 실제 소스와 시연으로 대조한다. 온보딩 조사 근거는 후속 TODO를 위해 보존한다. 그대로 재사용/갓생패치에 맞게 변경/채택 제외를 구분하고 기존 확정 사항과 충돌을 기록한다. 변경된 정본과 실제 검증 기준을 준비한다.

## T2 공통 UI 표현 및 피드백

T1에서 합의된 범위만 기존 SEED/공통 CSS·런타임에 적용한다. 버튼 및 타이포, 여러 화면의 동일 상태, 알림/모달·이펙트·애니메이션을 비교한다. 실제 모바일 폭, 라이트/다크, 글자 확대, 키보드·동작 감소, 상태/회귀 확인.

- 1차: 기존 공통 버튼 face, 아이콘, Filter Chip의 press/transition 및 native Switch 스타일을 기존 CSS에 추가. 실제 기능·승인 치수/브랜드 값 변경 없음. Switch는 소비 페이지 미연결이며 신규 설정을 만들지 않음. 테스트 2개 추가, 실제 Node/브라우저 실행 NOT RUN.
- 2차: 실제 웹 preview에서 `?design=refined`로 동일 데이터·라우트의 시각 비교안을 실행할 수 있게 연결했다. Root만 큰 제목/높이, Section·Hero·Number의 위계, 일반 Surface 면/곡률, 알림·메시지 시트의 내용 높이와 제목·여백, Dialog·Snackbar 진입 효과를 후보로 구현했다. 새 Page Type/Variant/기능·저장 변경 없음. 기존 D-015/토큰/기본안은 유지. Switch 소비 연결 및 퇴장 모션은 3차에서 처리.
- 3차: refined 메뉴에서 기존 다크 모드를 native Switch에 연결. 저장 키·기능 동일, 입력 포커스와 메뉴 유지. 기존 native dialog close를 지연하지 않고 지원 브라우저에서 display/overlay 퇴장 180ms를 적용, 미지원 환경은 즉시 닫기. Snackbar 퇴장/타이머 취소·동작 감소 대응. 새 기능/저장 구조 없음.
- 검증: 변경 전후 소스·정적 계약을 대조하고 테스트를 추가했다. 실제 Node/브라우저 및 실기기 NOT RUN. 2026-11-27 D-018: 웹 Preview/Lab은 [유물](../../../archive/README.md)로 전환. 추가 웹 구현·비교 렌더 게이트는 범위에서 제외하되 기존 미검증은 PASS로 바꾸지 않는다. 표현 후보·정본·에셋 보존. 다음: 실제 Android 기반 편입 후 앱에서 헤더·시트·스위치·타이포·박스·피드백 및 좁은 폭·라이트/다크·글자 확대·접근성·상태 회귀를 검증한다. T2 종결 아님.

### T2 종료 조건 (2026-11-27 범위 확정)

UI-001의 최종 단계는 T2이며, 목표는 실제 앱에서 재사용 가능한 디자인 표현 기반을 완성하는 것이다. 모든 제품 화면의 전면 개편, Android 기반 자체 이관, 온보딩, 출시를 이 작업의 종료 조건으로 확대하지 않는다.

| 종료 게이트 | 현재 상태 |
|---|---|
| 기존 SEED의 디자인 정체성·승인값 보존, 계승/변경/제외 구분, 중복 규칙 압축 및 관련 정본 갱신 | 부분 충족: 원칙·Overlay 등 정리 및 기술 후보 기록, 실제 앱 적용 결과에 맞춘 정본 최종화 남음 |
| 실제 앱 공통 Theme/컴포넌트에 버튼·타이포·표면/박스·Root/Standard 헤더·Sheet·Switch·Dialog/Snackbar·상태 모션을 연결하고 동일 역할의 표현을 일관되게 재사용 | 미착수: 웹 후보 및 코드 참고만 보존; Android 본체 미편입 |
| 실제 대표 소비 화면에서 정상/선택/비활성/실행/닫기 등 해당하는 상태와 전환 검증. 기존 네비게이션·데이터·보상/마스코트 및 기능 회귀 방지 | 미검증: 실제 앱 실행 필요 |
| 실제 대표 화면에서 좁은 폭, 라이트/다크, 글자 확대, 터치·접근성·동작 감소 검수 및 새 후보의 사용자 시각 승인 또는 승인된 기존 값 유지 | 미검증 |
| 필요한 테스트·실행 근거와 기준 SHA 기록, new2 반영 확인, 관련 정본/TRACE 갱신 | 웹 정적 근거만 존재; 앱 검증 및 종결 미완료 |

**현재 판정:** BLOCKED. T1 소스 비교는 정적 PASS, 웹 비교 렌더는 NOT RUN이며 유물화로 추가 웹 검증은 범위에서 제외한다. T2는 표현 후보의 웹 구현을 보존했지만 실제 Android 구현은 시작하지 못했다. 웹 후보의 존재나 정적 검사만으로 T2 진척률을 실제 앱 완료 비율로 환산하지 않는다. Android 기반 편입 후 실제 코드에 맞춰 작업 범위를 등록하고 T2를 재개한다.

**범위 변경:** 미착수였던 T3 온보딩은 사용자 요청에 따라 UI-001에서 제외하고 [전역 TODO](../../core/TODO.md)로 이관한다. 기존 조사 근거와 권한/접근성 원칙은 보존한다. T3 완료를 의미하지 않으며 번호를 다른 기능에 재사용하지 않는다. UI-001은 T1/T2 두 단계만 유지한다.
