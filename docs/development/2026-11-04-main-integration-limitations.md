# 2026-11-04 · main 통합 한계 및 미검증 사항

**상태:** 사용자 승인에 따라 개발 PR #6을 `main`에 우선 통합하는 범위 기록. **스토어 출시·프로덕션 기능 완성 판정이 아니다.**

## 변경된 범위

- 2026-11-03까지 개발 브랜치에 구현된 온보딩, 선택적 계정 연결, Room v5 데이터 이관, 로컬 우선 퀘스트, 인증·아웃박스·소셜 UI와 클랜 시각 구성을 유지하여 통합한다.
- `DailyQuestApp.kt`의 새 쪽지 시트에서 예시 `model.contacts`를 제거하고, 로그인된 사용자에게 서버 스냅샷의 **실제 직접 대화**만 보여 준다. 기존 대화가 없으면 빈 상태를 표시한다.
- `ClanPage.kt`의 영구 비활성화 `pendingClaims` 상태를 제거한다. 상자 수령은 **서버 확인 요청**으로 표시하며 실패 후 재요청을 허용한다. 반복 탭은 여러 명령을 아웃박스에 저장할 수 있어 **서버 멱등 처리에 의존**한다. 서버 실통합 테스트는 아래 미검증 사항에 남긴다.
- Supabase 운영 데이터베이스, 기존 사용자 데이터, 앱 패키지 ID, 서명 키, 기존 마이그레이션은 이 통합 작업에서 수정하지 않는다.

## 운영·후속 검증

1. 이 병합은 **개발 기준선(main) 확보**가 목적이다. 화면 완성 및 안전한 프로덕션 공개를 뜻하지 않는다.
2. `docs/superpowers/plans/2026-11-03-visual-release-gate.md`의 시각/E2E 출시 게이트는 **공개 출시 시 여전히 유효**하다. 이 문서는 `main` 코드 통합에만 허용된 예외를 기록한다.
3. 우선순위: (a) 정상 Android 기기/충분한 디스크의 에뮬레이터에서 실제 렌더 비교 (b) 운영 SQL 005 변경 사항 검토·배포 및 실제 클랜 계정 2개 E2E (c) 계정/오프라인/보상 중복·이관 회귀 검사 (d) Gemini 백엔드 구현 시 별도 확인.
4. SQL 005는 검증 없이 운영 DB에 적용하지 않으며, 실제 사용자의 개인정보를 캡처용 fixture로 사용하지 않는다.
5. 사용자에게 제공할 APK는 **main 워크플로 빌드 산출물**만 사용한다. 개발 브랜치 APK와 스크린샷 fixture는 제품 실행 성공 근거로 쓰지 않는다.
