# 마스코트·마이페이지 · 가장 개인적인 즐거움

## 1. 왜 마스코트가 핵심인가 [원칙]

> “그냥 단순히 학생들이 많으니까 익숙한 참잘했어 도장의 얼굴이아님.”

> “단순히 프사를 유지하는 것 보다 우리의 컨셉을 유지하면서도 엄청난 장식 없는 그냥 얼굴 같은 그릇을 만들고, 거기에 현실적인ㅇ 모자, 안경등을 씌우며 조합해서 자신의 얼굴을 표현할 수 있으며”

마스코트는 홍보용 캐릭터만이 아님. **사용자가 자신의 개성을 담는, 단순하고 일관된 얼굴 형태의 아바타**임. 도장 같은 붉은 얼굴은 브랜드 식별자이자 여러 패션 아이템을 받아들이는 '그릇'에 가깝다는 설명.

## 2. 실제 패션과의 대비 [원칙]

> “나아가 진짜 현실적인 패션의 아이템을 주니 ‘진짜 받은 것 같은 느낌’ 까지 줄 수 있는걸 원했음.”

얼굴 자체는 매우 단순하지만, 모자·안경·이어폰·헤드셋 등은 **현실에서 볼 법한 형태와 물성**을 가진 소품을 선호함. 두 요소의 대비가 포인트임.

- 마스코트는 꾸미기를 위해 형태가 계속 바뀌면 안 됨.
- 장착한 패션 아이템이 **내가 선택한 취향**으로 보이는 것이 중요함.
- 소품을 바꿔도 아바타의 핵심 얼굴 인식은 유지되어야 함.
- 현실적인 아이템과 단순한 도장 얼굴을 **억지로 똑같은 그림체**로 만들 필요는 없음.

위 내용은 아트 디렉션의 원칙이지, 정확한 얼굴 비율·아이템 레이어 좌표·장착 부위 규격이 이번 대화에서 확정되었다는 뜻은 아님.

## 3. 마이페이지는 '설정'이 아니다 [원칙]

> “궁극적으로 내 마이페이지와 내 마스코트를 내가 원하는대로 가꾸는것이 재밌는것이고, 애초에 보상도 다 그거에 관련된거임.”

마이페이지는 스펙/메뉴의 부속이 아니라 **내가 가꾼 결과와 취향을 확인하고 보여주는 목적지**가 되어야 함. 퀘스트는 그 공간에 자산과 이야기를 쌓게 하는 핵심 수단.

하지만 여기서 마이페이지를 기본 홈으로 고정하거나, 퀘스트 화면을 덜 중요하게 배치한다는 결론을 낼 수는 없음. 사용 빈도와 즐거움의 중심이 다르기 때문임.

## 4. 첨부 시각 자료의 역할

2026-11-04 대화에서 사용자 제공:
1. **금색 마스코트 코인**: 캐시의 상징과 물성. [REWARDS.md](./REWARDS.md) 참고.
2. **여러 모자/헤드폰을 착용한 마스코트 예시**: 얼굴은 유지하고 소품·표정의 조합이 아닌 **착용 아이템**으로 개성 부여.
3. **종이 위 붉은 도장 얼굴**: 최소한의 형태, 도장 질감, 브랜드 정체성.

이미지는 채팅에 첨부된 참고 자료이며 **이번 문서 커밋에서 이미지 파일을 새로 등록하거나 기존 에셋을 수정하지 않았음**. 향후 웹 시연에서는 저장소의 실제 이미지 파일과 이 참고 이미지를 대조해야 함.

## 5. 미결 사항

꾸미기 UI 구성, 개인·친구에게 보여지는 프로필 구성, 아이템 도감/상점, 실사풍 강도, 색상·질감, 에셋 재활용·조립 규칙과 가독성은 웹 프로토타입에서 합의해야 함.
