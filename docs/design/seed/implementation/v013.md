# 갓생패치 · v0.13 실제 재사용 리소스

> 이 디렉터리는 시연 HTML이 아니라 **개별 SVG 원본, 기계 판독 토큰, 구현 규칙**을 보관한다. 사용자 피드백으로 수정된 시각 실험안이며 Android에 배포된 코드 또는 디자인 최종 승인안은 아니다.

## 재사용 진입점

- [37개 개별 SVG](../assets/icons/v0.13/README.md): name.svg / name-fill.svg, 모두 24×24
- [디자인 토큰 JSON](./v013-tokens.json): Light/Dark, 간격, 반경, 아이콘, 뱃지, 바텀시트 제스처
- 상세 계약은 기존 정본을 읽을 것: [C-SVG](../components/svg-icon.md), [C-SURFACE](../components/surface-media.md), [C-SHEET](../components/bottom-sheet.md), [C-GESTURE](../components/gesture.md), [C-ACTION](../components/action-button.md), [P-BTN-ICON](../patterns/button-icon-layout.md)

## 적용 계약

1. `new`는 **docs-only 디자인 시드 브랜치**다. 이 자료를 곧바로 Android에 이식했다고 주장하지 않는다. 앱 리소스 변경은 `main`의 `AGENT.md` / `IDEA.md`를 읽고 별도 승인과 빌드·실기기 검증을 거친다.
2. 기존 Android 앱의 클랜 네비 아이콘은 **확정된 나침반**이고 이 실험의 `users`는 그룹/클랜을 나타내는 **후보**다. 기존 `app/src/main/assets/icons/svg/nav-*-clan.svg`를 자동 교체하지 않는다.
3. SVG Outline은 currentColor·둥근 cap/join, Fill은 별도 실루엣을 사용한다. 아이콘 크기를 전부 동일 숫자로 강제하지 않고 optical balance를 검사한다. 글자보다 아이콘이 과도하게 커지지 않도록 한다.
4. `home`, `home-fill`, `users`, `users-fill`은 v0.13 수정안으로 교체됐다. 나머지 33개는 v0.12 수준을 유지했다.
5. `user`와 `users`는 서로 다른 의미다. `chat`와 `chat-fill`처럼 Fill 쌍이 있는 것만 상태 전환한다. Fill 없는 도형에 CSS fill을 강요하지 않는다.
6. SVG의 `currentColor`는 UI 문맥의 semantic foreground를 상속한다. Fill 내부의 흰 구멍/체크 표시는 강제 tint 하지 않는다. Android VectorDrawable은 rect/circle/transform/currentColor를 변환해야 하므로 기존 `tools/sync_svg_icons.py`에 이 파일들을 **무검증 직접 투입 금지**.
7. 캐시 코인 원화는 여기서 벡터로 재생성하지 않는다. 실앱의 `res/drawable-nodpi/cash.webp`·`pile_of_cash.webp`를 정본으로 재사용. CashValue의 아이콘:값은 이미지 폭과 글자 기준선에 맞추고 포맷은 지역화한다.

## v0.09~v0.13 실험 결과 요약

- Surface: plain/solid/outlined/subtle/inset/raised/interactive/media/reward/overlay 10역할. 배치와 표면 책임을 분리한다. solid→solid→solid, raised→raised, reward→reward 중첩 금지.
- Component Gallery 30종 / Pattern 13종 / Gesture 6종으로 분류한 HTML 실험이 있었다. 시연 수량은 네이티브 구현 수량이 아니다.
- Progress는 단일 default 트랙을 기본으로 쓰고 목적이 명확한 feature만 변형. 임의로 같은 목적의 바를 중복 만들지 않는다.
- Checkbox/RadioChoice는 선택 상태와 비선택 상태 모두 명시하고 실제 사용자 이벤트에 연결. SegmentedControl은 **바깥 트랙 하나 + 선택된 알약 하나**, 이중 컨테이너 금지.
- Button Outline/Neutral은 기본 전경 중립색. Brand Weak는 별도 강조, Brand Outline이라 해도 테두리를 진하게 과장하지 않는다. 노란 Secondary CTA 다크모드에서 **흰색 아이콘+텍스트**, 배경 밝기를 함께 낮춰 대비 검증.
- Field focus는 2px 얇고 분명한 경계; 전역 input focus-visible의 두꺼운 반투명 링을 중복 상속시키지 않는다.
- Badge: neutral/brand/success/info/warning/danger/reward, 아이콘·도트 선택형, 기본 26px/XS21px, 미세한 border. 의미색을 브랜드색으로 통합하지 않는다.
- BottomSheet: Body 스크롤과 Sheet 높이를 연동. Body가 맨 위에서 아래로 당겨지면 Sheet 축소, 맨 아래에서 위로 밀면 확장; 스크롤 도중 경계에 도달하면 **같은 제스처의 남은 이동량**을 Sheet로 인계. 드래그 중 손을 실시간 추적, 놓은 높이에서 가장 가까운 closed/min/mid/full로 스냅. Footer 고정, Back/Esc 닫기, OS inset 준수.
- UI 다른 화면은 v0.13 SVG 수정 범위에서 의도적으로 보존했다.

## 진행 범위 / 미검증

- SVG 원본(37개) 생성·파일 등록과 기존 정본으로의 라우팅까지만 본 커밋에서 다룬다.
- SVG 브라우저 캡처와 모바일 Chromium 실험 검증은 이전 HTML 시안에 대한 기록이며, **이 커밋의 Compose 런타임/기기 검증을 대신하지 않는다**.
- 이미지 생성 초안의 선 깨짐은 SVG에 의도적으로 반영하지 않았다.
- v0.9 기반 레거시 CSS 전체 구조 물리 리팩터링이나 실제 Android 화면 매핑은 여기에서 하지 않는다.
