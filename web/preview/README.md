# 갓생패치 웹 시연

저장소 루트에서 정적 서버를 실행한 뒤 `/web/preview/`를 연다. `python3 -m http.server 8000`이면 로컬 주소는 `http://localhost:8000/web/preview/`이다. HTML·ES 모듈과 공통 SEED CSS, 저장소 에셋만 사용한다.

홈은 퀘스트·퀘스트북·클랜·친구 채팅·이벤트·보상함으로 직접 연결한다. 클랜 대화는 디엠의 같은 대화방을 연다. 페이지 흐름은 전체 페이지로 구성했다. 일체형 이미지 배너는 텍스트가 들어간 완성 아트가 필요한 이벤트에 적합하며, 이 시연에서는 시한·보상·상태가 데이터에 따라 바뀌어 실제 텍스트와 기존 재화·상자 오브젝트를 조합했다.

### 홈 상단 탐색

검색은 논글로벌 화면에서 퀘스트·퀘스트북 제목을 검색한다. 알림은 SEED 시트에서 열리고, 항목을 누르면 읽음 상태를 저장한 뒤 실제 목적지로 이동한다. 메뉴는 상단 드롭다운에서 퀘스트 만들기·보상함·꾸미기·테마 전환을 제공한다.

### 퀘스트 탭

상단 검색은 기존 검색 화면을 공유하며 검색 결과 상세에서는 퀘스트 탭을 유지한다. 만들기는 디엠과 같은 AI 대화로 연결한다. 퀘스트북은 표지 전체가 상세 진입점이며, 완료 수는 해당 북의 퀘스트와 함께 갱신된다. 내 퀘스트 목록은 상태 필터 아래에 결과 행을 바로 표시한다.

### 상점

상점은 기존 카탈로그와 로컬 보유·캐시를 기반으로 운영되는 Global Inner 웹 시연이다. 추천 아이템은 고정 큐레이션이며 할인·실제 인기·일일 갱신을 뜻하지 않는다. Filter Chip은 기존 `전체/모자/오디오`를 실제 상품 목록에 적용한다. 일반 상품은 이미지 1:1 contain/Plain 오픈 진열로, 추천 상품은 같은 C-IMAGE의 가로형 통합 카드로 표시한다. 보상 상자는 판매 품목이 아니고 잠긴 클랜 상자는 클랜 목표로, 수령·개봉한 상자는 보상함으로 이동한다. 캐시 구매·구독·확률형 판매 및 운영 정책은 추가하지 않았다. 화면 폭 360px 미만에서는 잔액을 본문 상단에 표시한다. 실제 모바일 픽셀·크롭·터치 검증은 별개다.

### 클랜 탭

`내 클랜`은 팀 정체성·공동 상자·멤버·대화, `인사이트`는 이번 주/지난주 합계와 기여 순위, `클랜 상점`은 기존 카탈로그 장식·공유 캐시·구매 상태로 분리했다. 탭 전환은 한 페이지 안의 패널만 교체하며 Root와 하단바는 그대로다. 비참가 상태는 로컬 시연 `clanJoined`가 결정하며 가상 가입/나가기 후에도 이전 보상과 메시지 기록을 보존한다. 클랜 재화/할인/별도 서버 가입·실시간 동기화는 아직 정의·구현되지 않았다. 멤버 실제 공개 범위는 제품 논의 사항이며 표시 데이터는 시연용이다.

## 구현 순서와 데이터 경계

글로벌 탐색과 화면별 첫 주목점 → 상세·대화·꾸미기의 페이지 분류 → 수락/완료/보상 루프 → 폭·상태·회귀 검증 순서로 작업한다. `mock-data.mjs`는 시연용 목표, 상품, 메시지, 보상과 초기 상태를 제공한다. `store.mjs`는 저장·전이·가상 응답을 담당하고, `views.mjs`와 `app.mjs`는 화면과 사용자 입력을 담당한다. 저장은 브라우저 로컬이다. AI 대화, 구매, 메시지와 보상은 실제 서버에 연결되지 않는다. XP는 진행·클랜 기여, 캐시는 구매에 사용한다. 금액과 목표치는 시연용이다.

## 검증

저장소 루트에서 `node --test web/preview/preview.test.mjs`를 실행한다.

### 검증 결과

- 시연 동작 12개와 공통 SEED 품질 검사 8개가 통과했다. 시연 검사는 페이지 타입, 부모 탭, 수락부터 완료·보상·취소까지의 전이, 클랜 상자, 제안 수정, 증빙, 구매·장착, 이벤트 연결, 홈의 대표 도전 교체와 수령 상태를 포함한다.
- 16개 화면 마크업의 링크 중첩, ID, 폼 라벨을 확인했다. 정적 서버에서 진입점·모듈 MIME·공통 CSS·런타임·아이콘 11개 응답을 확인했다.
- [D-017](../../docs/DECISIONS.md)의 가로형 대표 상품과 3열 오픈형, 반응형 잔액, 필터칩, 기간 선택의 공통 스타일을 대조했다. 퀘스트의 기한과 클랜 주차는 고정된 시연 데이터이며 실제 시간에 따른 만료·정산은 이 예시의 범위 밖이다.
- 홈은 GitHub Pages 데스크톱 Chromium에서 화면과 보상 아트를 확인했다. 홈에서 퀘스트 상세에 진입해 완료한 뒤 돌아오면 완료 수가 0에서 1로 증가하고 해당 항목이 진행 목록에서 사라졌다. 완료 취소 후 완료 수가 0으로 돌아왔다. 모바일 화면의 320·360·390·430px 픽셀, 200% 글자, 실기기 터치와 다른 페이지의 종합 시각 검수는 미확인이다.
