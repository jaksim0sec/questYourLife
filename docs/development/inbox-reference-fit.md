# 알림창 시안과 액세서리 회귀 수정

액세서리 회귀 원인: 1280px 참고 이미지에서 약 200px로 표현된 아바타의 이동량을 100px 기준으로 환산해 이동이 두 배가 됐다. REFERENCE_SIZE_PX=200으로 고정하고 모든 보정은 이 디자인 좌표계에서만 환산한다. 화면에서 측정한 크기로 기준을 다시 바꾸지 않는다. 기존 얼굴 레이어/PNG와 다온 캡은 그대로다. 크기는 현재 액세서리 중심 기준 비율이다. 모찌/하루의 같은 원본 캡은 기존 두 착용 보정값을 유지한다.

실제 PNG·동일 합성 좌표로 100/200 기준의 정적 비교 이미지를 개발 환경에 생성해 전후를 확인했다. 기기 스크린샷이 아닌 액세서리 조합 검증 이미지다. 코드에서 지정한 얼굴·다온 불변과 모든 항목의 이동/비율을 회귀 테스트로 검증한다.

알림창: 상단 설정/닫기, 고정 전체/친구/클랜 탭과 진한 선택선, 오늘, 읽지 않음 점/아바타/굵은 본문/보조 문구/우측 시간/구분선, 고정 ‘모두 읽음으로 표시’의 구조를 구현한다. 공통 시트에 헤더 액션과 고정 헤더 콘텐츠, 콘텐츠 여백/간격 슬롯을 추가했다. 탭과 하단 동작은 목록 스크롤과 분리된다.

첨부의 친구·클랜 활동 4건은 시연 데이터로 안내한다. 읽음 상태는 patch_inbox_read에 저장하고 개별 클릭/모두 읽음에 반영한다. 각 행은 프로필 또는 클랜으로 이동한다. 전체 탭 아래에는 실제 일일 퀘스트 제안/진행/완료 기록을 유지하고 수락/거절 동작을 보존한다. 헤더 설정은 실제 설정으로 연결한다. 실제 친구/클랜 이벤트 수신은 아직 미구현이다.

기기·에뮬레이터는 사용자 지시대로 실행하지 않는다. 알림창의 최종 크기·스크롤/드래그와 액세서리의 실제 기기 합성 위치는 미검증이다.

소스 검토에서 알림의 아바타 착장이 프로필과 다른 문제 및 프로필→알림→다른 프로필 이동 시 복귀 경로가 자기 자신이 되는 문제를 수정했다. 모든 사람 그림은 동일한 아이템 매핑/보정을 사용하고 이미 프로필에 있으면 기존 복귀 경로를 보존한다. 테스트 20개 실패·오류·건너뜀 0개(`/workspace/inbox-fit-final.log`). 최종 UI 수정 후 APK를 다시 빌드한다(`/workspace/inbox-final-apk.log`).

최종 확인: 목록 행 간격을 첨부 밀도에 맞춰 조정한 APK 빌드 성공(`/workspace/inbox-density-final.log`). 기기 검증을 대신하는 결과는 아니다.
