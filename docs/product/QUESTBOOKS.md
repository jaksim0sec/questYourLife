# 퀘스트북 · 현실의 도전을 담고 진행하는 콘텐츠

> **2026-11-12 최신 방향:** 퀘스트북의 최우선 역할은 습관·루틴·목표 달성의 진행과 성취를 담는 것이다. 사용자 콘텐츠의 자연스러운 공유는 가능하지만 **트렌드 형성·랭킹·콘텐츠 SNS화는 필수 목표가 아니다**. [D-017](../DECISIONS.md), [QUESTS](./QUESTS.md) 참고.

## 1. 현재 역할 [원칙]

- **개인 수행 공간:** 목표와 퀘스트의 목적, 현재 단계, 다음 행동, 진행 기록, 성취와 보상을 한 단위로 보여준다. '웹툰 표지'를 먼저 배치한 뒤 체크리스트를 끼워 넣는 접근은 지양한다.
- **실질적 이용:** 사용자가 오늘 무엇을 할지 쉽게 이해하고 바로 수행하도록 돕는다. 습관·루틴이 우선이며, 장기 목표 달성은 베타다.
- **AI 기반 운영:** AI가 퀘스트북의 내용을 제안·분해하고, 수락된 범위 안에서 다음 행동·진행 조정안을 제공한다. 사용자의 수락 없이 공동 목표나 진행 기록을 변경하지 않는다.
- **선택적 소셜:** 이용자가 원할 때 공유·참고·참여하며 친구와 함께 도전할 수 있다. 타인이 참여해도 각자의 실제 진행·완료 기록은 독립적이어야 한다.
- **시각적 현실성:** 모든 퀘스트북에 독립적인 고유 일러스트를 만들지 않는다. 공통 아트셋·썸네일 요소·텍스트·진행 상태를 재조합하는 방식으로 다양한 콘텐츠를 구분하는 방향을 검토한다. 정확한 표지 UI와 에셋 규격은 아직 미결이다.

퀘스트북이 **모든 단일·클랜·서버 보너스 퀘스트에 반드시 필요한 컨테이너**라는 뜻은 아니다. 퀘스트북에 묶을지 여부는 해당 도전의 진행 목적에 따라 판단한다.

## 2. 기본 정보와 참여 [구상]

| 정보 | 화면에서 해야 하는 일 |
|---|---|
| 목적과 진행 형태 | 습관인지, 루틴인지, 장기 목표인지 이해 |
| 현재 상태·진행률 | 지금까지의 진행과 다음 단계 파악 |
| 수행할 퀘스트 | 실제 행동으로 곧바로 연결 |
| 완료 기록·성취 | 무엇을 지속했고 이루었는지 확인 |
| 보상 연결 | XP·Cash·상자·꾸미기와 성취의 관계 표시 |
| 공유 및 협업(선택) | 허용된 사람과 참고·공동 참여 |

위 항목은 UX 의미 정의이며 고정 카드·필수 필드·DB 스키마 확정이 아니다. 공개·원본·참여 버전·편집 권한과 개인 완료 원장 구분은 별도 설계가 필요하다.

## 3. 과거 콘텐츠 플랫폼 구상 [원 발언 보존 · 우선순위 변경]

> “플랫폼 내에서 \"트렌드\"가 형성될 수 있는 환경이여야함.”

> “따라서 나는 퀘스트를 \"퀘스트북\"으로 묶어서, 마치 방탈출이나 로블럭스의 인기 게임처럼, 공유하고 수정하고 사람들이 참여하고, 이들이 랭킹이 생기고, 경쟁하거나 참고하고, 소통하는것임.”

위 표현은 2026-11-04~06 당시의 구상 기록이다. 원래는 사용자가 만든 퀘스트북이 공유·참여·수정·전파되며 유행이 생기는 플랫폼을 생각했다. **2026-11-12에는 억지로 트렌드를 만들려다 퀘스트 본질을 해칠 수 있다는 판단으로 우선순위를 조정했다.** 공유나 사용자 제작 가능성을 삭제한 것이 아니라, 퀘스트북의 성공 기준을 인기·유행으로 강제하지 않는 것이다.

## 4. 미결 범위

퀘스트북의 정확한 포함 조건, 개인/공동 진행 표시, 기본 화면 구도, 표지 재조합 규격, 원본·참여 버전·리믹스·저작자 표시, 공개 범위, 실제 데이터 모델, 검색·추천·랭킹을 제공할지 여부는 [OPEN](../OPEN.md)에서 분리한다.
