## 판단 등급
직접 관찰 / 추론 / 설계 제안 / 사용자 승인 지위를 별도로 남긴다. 관찰 confidence high여도 approved가 아니다. 이미지 미노출 상태·정량 토큰은 proposed, 실행·시각 검수가 필요한 항목은 needs-validation이다. 이 시드에서 참조하는 기존 상단 시각 승인 정본은 D-011이며 새 문서의 상태 변경은 DECISIONS/OPEN 정본을 통해 관리한다.
