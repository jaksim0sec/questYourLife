# UI-001 · 갓생알리미 기술 계승

- 상태: PROPOSED, 미착수. 선행: INFRA-001. 요청된 방향은 버튼·타이포 활용, 디자인 완성도와 일관성, 온보딩, 이펙트·알림창·애니메이션 등 갓생알리미에서 익힌 구현/표현 기술의 계승.
- 비목표: 갓생알리미의 화면·브랜드를 그대로 복제하거나 갓생패치의 소셜 퀘스트·도장 마스코트·보상 정체성을 덮어쓰기. 권한·개인정보·동작 감소 등 접근성 경계 보존.
- 원본 저장소와 실제 컴포넌트, 온보딩/권한 흐름은 아직 조사하지 않았다. 기존 [SEED](../../../seed/INDEX.md) 승인 범위와 [OPEN](../../OPEN.md)의 미결을 비교한다.

## T1 기술 비교 및 계승 기준

버튼 상태·타이포 위계·여백/표면·디자인 일관성·이펙트·알림창/시트·모션·온보딩을 실제 소스와 시연으로 대조한다. 그대로 재사용/갓생패치에 맞게 변경/채택 제외를 구분하고 기존 확정 사항과 충돌을 기록한다. 변경된 정본과 실제 검증 기준을 준비한다. NOT RUN.

## T2 공통 UI 표현 및 피드백

T1에서 합의된 범위만 기존 SEED/공통 CSS·런타임에 적용한다. 버튼 및 타이포, 여러 화면의 동일 상태, 알림/모달·이펙트·애니메이션을 비교한다. 실제 모바일 폭, 라이트/다크, 글자 확대, 키보드·동작 감소, 상태/회귀 확인. NOT RUN.

## T3 온보딩 경험

T1의 기술 비교와 T2의 공통 UI를 기반으로 진입·설명·권한 요청·거부·재시도·완료/재진입 상태를 시연한다. 실제 Android 권한과 웹 모의 흐름을 구분하며 강제 동의나 불필요한 요청을 피한다. NOT RUN.

최종 게이트: 사용자 시각 승인 범위와 실제 기능 검증 분리. Android 이관과 출시 자체는 별도 범위. T 분할은 작업 시작 전 검토 가능하며 시작한 ID는 고정.
