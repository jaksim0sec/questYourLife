# 마이·꾸미기 시안 반영과 공통 시트

2026-11-02. 기준은 사용자가 제공한 02번 시연의 가운데 마이와 오른쪽 꾸미기 화면이다. 클랜 본문과 하단 내비게이션은 앞선 변경을 유지한다. 사용자의 지시에 따라 에뮬레이터·기기 실행은 하지 않는다.

## 화면별 기준과 구현

- 마이: 공통 헤더/탭 아래 얼굴·이름·클랜·프로필 꾸미기, 두 캐시 영역, 이번 주의 나, 세 도장 자리, 보관함/성취 기록/알림 설정 순서로 구성한다. 좌우 16dp, 영역 사이 8–12dp를 적용한다. 좁은 폭과 큰 글씨에서는 얼굴/소개와 두 캐시 영역을 세로로 배치한다.
- 개인 이름은 로컬 프로필이 없는 현재 상태에 맞춰 `나`로 표시한다. 시연용 클랜임을 명시한다. 캐시·주간 획득·완료 수·실천 일수는 실제 Room 기록이다. 연결된 일일 퀘스트와 부모 단계는 한 행동으로 세고, 주간 획득은 구매 비용과 분리한다. 날짜는 한국 시간의 월요일 기준이다.
- 첫 시작·7일 연속·첫 챕터 도장은 로컬 완료 기록으로 획득 여부를 계산한다. 별도 캐시를 지급하지 않는다. 도장 그림은 빈 슬롯이며 조건은 시트에서 확인한다.
- 꾸미기: 뒤로/제목/캐시, 회색 얼굴 미리보기, 추천/모자/소품/보관함 탭, 노란 클랜 보상 안내, 두 열 상품 목록, 하단 고정 착용 모습 보기 순서다. 좁은 폭·큰 글씨·긴 잔액에서는 캐시를 제목 아래로 옮긴다. 공통 셸의 시스템 인셋을 사용하며 꾸미기에는 하단 탭을 중복 표시하지 않는다.
- 모자·헤드폰·소품·도장 그림은 새로 생성하거나 대신 그리지 않았다. 제공된 고해상도 기본 얼굴만 사용하고 필요한 이미지 공간을 남긴다. 저장한 착용 항목은 이름/테두리로 표시하며 실제 착장 합성은 미구현이다. 클랜 보상 수령도 미구현인 데모 안내다.

## 구매 데이터와 아이콘

`CosmeticCatalog`에서 신규 구매 가격을 고정한다. 기존 기본 아이템 0과 블루 캡 2의 식별자를 유지하고 신규 소품은 1001/1002를 사용한다. 다른 기존 구매도 보관함에서 저장된 식별자/가격 그대로 표시하고 재구매 없이 착용한다. 기본 아이템은 무료다. 구매 시 기존 Room 트랜잭션으로 잔액·중복 소유를 다시 확인한다. 처리 중 중복 요청, 잔액 부족과 저장 오류를 UI에 반영한다. DB 스키마·패키지·저장 설정 키는 바꾸지 않는다.

새 아이콘은 `assets/icons/svg`의 arrow-left, chevron-right, shirt, chart-bars, flag, coin, bell, close, check 원본이다. 24×24, 둥근 끝/연결부와 2px 선을 사용한다. 파일명에는 사용하는 페이지를 고정하지 않는다. `tools/sync_svg_icons.py`로 Android 벡터를 등록했다.

## 바텀시트

공통 `PatchSheet`에 Material3의 반열림/펼침/숨김 앵커와 기본 드래그·플링·중첩 스크롤을 사용한다. 짧은 내용도 세로 공간을 확보하여 반열림과 펼침 상태가 생기게 한다. 손잡이 탭으로 펼침/반열림을 전환하고 닫기 버튼은 숨김 애니메이션 후 제거한다. 제목과 닫기는 고정하고 내용 영역만 스크롤한다. 메뉴·알림·퀘스트·클랜·도장·꾸미기 시트가 같은 동작을 사용한다.

## 검증 범위

- 구매 정책 단위 테스트: 기존 보유 아이템 무료 착용, 미등록 아이템 구매 거절, 기본 아이템 무료, 잔액 부족 거절, 카탈로그 가격 및 재구매 방지. 미구현 정책에서 5개 실패를 확인한 후 구현했다.
- 별도 에이전트의 소스 검토로 화면 순서·공통 인셋·구매/착용 연결·시트 상태를 검토한다. 임시 작업 트리에 심은 64dp 여백 차이를 검토자가 찾았으므로 이 검토의 소스상 여백 탐지는 확인했다. 크기·색·스크롤·제스처 감각까지 검증한 것은 아니다.
- 빌드와 최종 테스트 결과는 아래에 기록한다. 사용자 기기의 실제 렌더링, 터치/스크롤/키보드, 화면 회전, 시트 제스처의 부드러움, 앱 덮어쓰기 및 재실행 후 유지 여부는 **미검증**이다. 사용자가 직접 확인한다.

### 최종 확인

- `gradle --no-daemon --max-workers=2 :app:assembleDebug :app:testDebugUnitTest` 성공. 최종 소스 실행 로그: 개발 환경 `/workspace/profile-decor-final.log`.
- 단위 테스트 12개 실행, 실패/오류/건너뜀 0개. 구매 정책 5개와 기존 계획/클랜 정책 7개를 포함한다.
- 신규 SVG 원본 9개와 생성된 VectorDrawable 일치, `git diff --check`, `apksigner verify` 성공. APK 이름 `갓생패치`, 기존 `com.questyourlife.app.preview` 식별자 확인. 로컬 APK는 설치·배포하지 않았다. 사용자용 APK는 main의 기존 Actions 빌드 경로를 사용한다.
- 별도 검토자가 두 페이지와 공통 시트를 비교했다. 소스상 중요한 구성/구매 계약 차이는 발견되지 않았다. 꾸미기 헤더의 긴 잔액/큰 글씨 위험은 세로 전환으로 보완 후 재검토했다. 최초 20개 파일/9회 검색과 후속 1개 파일/1회 검색을 확인했다. 기기 렌더 검토와는 구분한다.
