# Page shell demo

Repository-managed source: `index.html` (shell markup), `shell.css` (shared styles), `app.js` (page slots, routing and interactions). The existing branch-root GitHub Pages Jekyll build renders `index.html`; both CSS and JS query versions and the `demo-revision` meta tag use `site.github.build_revision` automatically. Keep this front matter and both versioned references when editing. For a faithful local preview, use a GitHub Pages-compatible Jekyll installation (`jekyll serve` from the repository root, or `bundle exec jekyll serve` if using a local Gemfile) and open `/web/demo/`; a plain static server does not render Liquid/front matter. No custom deployment workflow or Pages settings change is required. The HTML itself may still be cached by the browser/CDN. Update these files on new2, not separate standalone HTML copies. Source SVGs are referenced from the shared assets tree. Global routes retain the large left-aligned Root header and clear outline actions. Global Inner and Non-Global share the centered-title Standard header and circular neutral actions. Bottom navigation is icon-only, neutral active Fill/inactive Outline with accessible names.
