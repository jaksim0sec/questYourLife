## 좋은 사례에서 가져온 원리

- **당근 SEED:** Action Button은 강조 단계와 상태를 갖고, 강한 CTA는 핵심 행동에 집중한다. Top Navigation은 Root/Standard를 구별한다. 우리에게 필요한 것은 주황색 복제가 아니라 역할과 조작의 일치다.
- **토스 TDS:** ListRow의 left/contents/right를 분리하고 필요에 따라 간격·구분선·반응을 조정한다. Typography는 역할과 확대 대응을 정의한다. 우리 시연의 작은 본문과 임의 굵기를 공통 역할로 연결했다.
- **치지직:** 제작사 Brenden은 주파수·헤르츠를 사선 그래픽과 확장 가능한 시스템으로 연결한다. 우리도 도장 얼굴·현실 패션·획득물이라는 자기 언어를 유지해야 한다. 공개된 브랜드 케이스를 치지직의 비공개 UI 토큰 규격인 것처럼 말하지 않는다.

## 원인 구분

확인된 사실: CSS transform으로 헤더 glyph가 실제 target 중심에서 약 8.5px 벗어났고, 320px/200%에서는 피드·랭킹 본문 폭이 줄어 한 글자 열이 됐다. viewport overflow만 검사하면 이를 놓친다.

설계 원인: 시드의 역할이 코드 변수로 충분히 연결되지 않아 화면마다 수치가 새로 생겼다. MHTML 보존 CSS 위에 반복된 국소 보정이 실제 레이아웃 검증을 대신했다. '아트를 크게' 같은 규칙만으로는 배경·문구·CTA의 경쟁을 해결할 수 없다.

제품 가설: 재방문 동력은 거대한 보상 배너보다 친구의 새 활동·내 캐릭터 변화·참여할 도전이 이어지는 경험일 가능성이 있다. 이를 효과로 확정하려면 청소년 대상 과업 테스트와 반복 이용 관찰이 필요하다.
