# 입력창·헤더·시트 높이 보정

사용자 실기기 사진을 기준으로 수정한다. 채팅 컴포저는 BasicTextField와 전송 버튼을 독립된 두 자식으로 배치한다. 전송 버튼은 바깥 여백과 고정 폭을 확보하며 텍스트는 남은 공간에서 최대 3줄이다. 강조된 빨간 외곽선 대신 밝은 입력 표면과 전송 버튼으로 계층을 구분한다. IME 위 배치는 유지한다.

알림·더보기는 공통 96dp Row 안의 48dp 버튼 두 개다. 대화 헤더의 우측 여백을 글로벌과 같은 8dp로 맞추고 외부 자식 간격이 아이콘 사이에 중복 적용되지 않도록 한다.

PatchSheet는 optional initialHeight/startExpanded로 시작 높이와 native 중간 앵커 사용 여부를 지정한다. 멤버 시트는 최대 10명의 행 수로 기본 높이를 정하고 그 높이에서 열린다. 확인 버튼은 공통 footer로 이동한다. 내용만 스크롤하며 footer는 현재 보이는 높이 안에 고정된다. 설정형 시트는 손잡이 탭 또는 위 스와이프로 전체 높이, 아래 스와이프로 기본 높이, 기본 높이에서 아래 스와이프로 닫는다. 기본 설정의 기존 시트들은 Material3의 중간/전체/닫힘 동작을 유지한다.

파츠별 관찰: 현재 사진의 비니·캡은 머리 위로 떠 있고, 헤드폰의 하단이 얼굴 중간에서 끝난다. 비니·캡의 폭을 조금 늘리고 내려 이마와 챙을 연결한다. 버킷·뒤로 쓴 캡은 각 실루엣 비율을 따로 유지한다. 크림/블랙 헤드폰은 아래로 옮겨 귀를 감싼다. 얼굴 원본과 아이템 ID는 유지한다. 보정값은 AvatarComposer 한곳에서 사용한다.

기기·에뮬레이터 실행은 사용자 지시에 따라 생략한다. 실제 입력창 높이/키보드, 시트 드래그와 footer 위치, 합성 파츠의 최종 시각적 정렬은 실기기 미검증이다.

검증 결과: assembleDebug·testDebugUnitTest 성공, 기존/합성 계약 테스트 15개 실패·오류·건너뜀 0개. 로그는 개발 환경 `/workspace/composer-sheet.log`. 별도 소스 검토에서 차단 결함은 발견되지 않았다. 높이 애니메이션 중 native 앵커 갱신과 손잡이/본문 제스처의 실제 상호작용은 기기 검증 대상이다.
